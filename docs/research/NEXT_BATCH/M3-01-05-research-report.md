# M3-01~M3-05 자료조사 및 문제 초안

- Curriculum Architect의 `0.1.0-draft` 명세 5개를 기준으로, src/data 경로에 단원별 content-draft를 작성하고 연습용 문항 초안 30개를 구성했다. 단원마다 6개 설명 섹션과 단계별 계산 예제가 있다.
- 교육부 고시 제2022-33호 안내 페이지를 2026-11-02에 확인했으며 수학과 별책 8이 고시의 별도 첨부임을 확인했다. 별책 본문에서 M3-01~05 각각의 공식 성취기준 코드/문구와 프로젝트 제안의 대응을 확인하지 않아 공식 매핑은 미검증이다.
- 외부 교재·기출·교육부 원문 문장을 복사하지 않았다. 첨부 원문의 라이선스·재사용 조건은 별도 확인하지 않았다.
- 모든 콘텐츠와 문항은 draft, 공개 승인 없음, humanVerified=false다. 정답은 작성자 자체 계산 대조이며 사람의 독립 수학·교육 검수는 아니다.
- 각 단원은 별개의 전략을 갖는 두 문제 원형을 제안했지만, 원형 분류·난이도는 실제 학생 반응과 사람 검수 전이다. 연습 6개는 제작량이며 권장 필수 풀이량과 은행 목표를 뜻하지 않는다.
- 렌더링 상호작용은 `polynomial-terms`, `polynomial-multiplication`, `polynomial-division`, `identity-coefficients`, `remainder-theorem`을 요청한다. 현재 계약/렌더러에 미지원이므로 Developer 구현 전 콘텐츠 런타임 검증은 불가하다.

## Curriculum 교차 검토 반영

- M3-01 설명에 한 문자 다항식의 지수 범위(0 이상의 정수)와 음·분수 지수 제외를 넣었다. M3-02의 대칭식 전개는 완전제곱식과 합차 곱 공식으로 한정했다.
- M3-03 문항 원형을 이차식 제수 긴 나눗셈과 x−a 조립제법으로 분리했고, x−a 외 상수배 일반화는 초안 범위에서 제외했다. 6개 정답을 자체 재계산했다.
- M3-04 수치 대입은 미지 계수에 필요한 독립 조건을 얻는 용도이며 유한 대입만으로 임의 다항식 항등식을 증명하지 않는다고 명시했다.
- 화면 예제의 문제·답·풀이 순서는 Curriculum 명세와 맞췄다. 데이터와 문항은 계속 draft, humanVerified=false, 사람 승인 0이다.

- 최종 정답 재대조: M3-03 m303-p03의 몫은 x+2, 나머지는 2x+3으로 정정하고 per-unit/group blueprint에 동기화했다. 정답 선택지 B이며 검산식은 (x²+1)(x+2)+(2x+3)=x³+2x²+3x+5다. 작성자 자체 계산 확인이며 사람 검수·승인 없음.
