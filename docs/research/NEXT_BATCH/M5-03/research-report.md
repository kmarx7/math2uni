## 공식 자료에서 확인한 범위

교육부의 2022-12-22 고시 페이지는 수학과 교육과정이 별책 8임을 명시하고, 별책 5~14 묶음 ZIP을 제공한다. NCIC 공식 통합검색에도 `[별책8] 수학과 교육과정.pdf/.hwp` 첨부 항목이 표시된다. 두 경우 모두 별책 8 원문 파일을 열어 이 단원에 해당하는 성취기준 문구·코드를 직접 대조하지 않았다. 따라서 `M5-03`에 공식 코드나 세부 성취기준을 연결하지 않는다.

교육부의 2023-12-27 확정 보도자료는 2028 입시에서 국·수·사·과 선택과목 없는 통합형 수능 및 심화수학(미적분Ⅱ·기하) 제외 정책을 알린다. 교육부의 2025-04-15 안내 페이지는 출제과목 변동 영역 예시문항 PDF를 제공한다. 해당 확정안과 예시문항 PDF 첨부를 본문 수준에서 열어 분석하지 않았으므로 이 자료만으로 `M5-03`의 직접 출제 여부, 필수성 또는 세부 출제 범위를 판단할 수 없다.

## 교수학습 및 오개념 근거 상태

이번 조사에서 이 단원의 특정 교수법 효과나 학생 오개념 빈도를 입증하는 직접 연구를 확인하지 않았다. 아래 주의점은 경험적 주장 대신 정의·조건 및 선수관계에서 도출한 설계 가설이다.

## 단원별 설계 메모 (가설)

실수 로그의 정의역·밑 조건(통상 진수 양수, 밑 양수이면서 1이 아님)을 정의와 동치 변환에 함께 유지한다. 0<a<1일 때의 단조성은 시각화에서 확인할 수 있으나 공식 성취기준 연결은 원문 대조 전까지 미확정이다.

## 권리 및 공개 상태

외부 교재·기출·예시문항을 복사하거나 변형하지 않았다. 교육부 페이지의 공공누리 출처표시 안내는 확인했으나 대용량 첨부물의 원문 이용 조건은 별도로 검토하지 않았다. 이 파일은 출처 조사 초안이며 문항/콘텐츠 초안을 포함하지 않는다. 사람 검수 전 게시할 수 없다.

## 인계

Curriculum Architect의 안정화된 단원 명세와 원문 별책 8을 대조하기 전까지 공식 성취기준 연결은 비워 둔다. 문제 원형과 콘텐츠 초안은 이번 작업 범위에서 작성하지 않았다. 상세 URL·확인일·한계는 `sources.json` 참조.

## 자체 제작 초안 산출 (검수 대기)

- 명세 계약대로 서로 다른 사고 구조 3개를 ProblemFamily로 분리했다. 각 가족에 서로 다른 두 연습 목표/문항을 배치해 총 6개 문항 인스턴스를 작성했다.
- 인스턴스 수는 가족 수와 혼동하지 않는다. 수치만 바꾼 추가 변형은 새 원형으로 집계하지 않는다.
- 문항은 자체 작성이며 외부 기출·교재·예시문항을 복사하지 않았다. 정답/풀이를 정의·조건에 대입하여 작성자 자체 점검했다. 독립 Curriculum 검토와 사람 검수는 대기 중이다. 모든 문항은 `draft`, `humanVerified:false`, 게시 승인 false이며 평가 인스턴스는 0개다.
- 콘텐츠 초안은 명세 소단원 문구를 구조화한 연구 초안으로, 공개 가능한 승인 콘텐츠가 아니다.
- 정확한 수량: 3 ProblemFamily, 6 draft practice items, 0 assessment items, 0 human-approved items.
- 명세 경로: `docs/specifications/NEXT_BATCH/M5-03/content-draft.json`; 문항 경로: `problem-blueprint.json`.

## 명세 범위 반영 메모

- 단조성 가족의 두 번째 문항은 표에서 대응값과 증가·감소를 비교하는 문항으로 정리했다. 로그 부등식 풀이와 부등호 방향 전환은 이 단원의 현재 명세 범위에서 제외했다.

## 선택지·목표 구체화 검토

- 6개 초안의 정답 선택지 위치를 A/B/C로 분산했고 각 answer key와 해당 선택지 내용을 대조했다. 학습 목표는 각 연결 문항의 구체적인 수학 행동으로 개별 작성했다.
- 여섯 번째 문항은 표의 대응값과 그래프 단조 방향만 비교하며 로그 부등식 해법은 요구하지 않는다.

- 선택지 정답 위치는 A/B/C 각 2개로 분산했다. 각 목표를 문항별 수학 행동으로 구체화하고 draft preview용 런타임 ContentDocument를 `src/data/proposal-lessons/drafts/M5-03.json`에 동기화했다. 단원 콘텐츠는 계속 비승인 상태다.

## 독립 검토 반영

- 최신 검토 수정: draft-06은 표의 대응값과 로그 그래프 단조 방향만 비교한다. 로그 부등식 풀이 및 해집합 결정은 요구하지 않는다.

- 최종 문항 무결성 점검에서 선택지 중복을 제거하고 answer ID·표시 순서·정답 텍스트의 대응을 재검증했다. `npm run content:validate`는 기존 M1 proposal-preview 기대 문항 수(480 대비 510) 불일치로 한 테스트가 실패했으며, 이번 M4/M5 신규 런타임 JSON은 해당 명령의 명시 테스트 목록에 포함되지 않는다. 별도 M4/M5 통합 스키마 검증 대기.

- 후속 의미 검수에서 선택지별 정답을 문항 계산과 직접 대조했다. 수정 후 30개 문항 모두의 정답 텍스트와 answer key가 일치하고, 선택지 중복이 없으며, 단원별 A/B/C 정답 위치는 2개씩 분산된다.

- 최종 검토 수정: 세 번째 원형은 밑 구간별 로그함수의 증가·감소 비교로 명명했다. draft-06은 a>1/0<a<1 단조 규칙을 log₂x와 log_(1/2)x에 적용하고, 한 표 행을 단조성 증거로 오해하거나 부등식을 푸는 요구를 하지 않는다. 관련 학습 목표와 미리보기 연습 안내도 동기화했다.
