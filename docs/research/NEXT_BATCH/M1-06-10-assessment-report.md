- 공식 성취기준: 매핑 미검증, 임의 코드 생성 없음

문항은 단항식 연산·동류항·분배법칙·등식의 성질·일차방정식 풀이/검산 목표를 나누어 표집했다. 연습 원형은 기존 M1-06~M1-10 가족에 연결해 평가 문항이 새 연습 원형 수를 부풀리지 않도록 했다. 입력은 객관식과 정수만 사용한다. 각 답은 작성자가 식과 정의로 재계산했으며 데이터의 허용 답 형식·서버 채점 결과와 대조했다. 이는 독립 검수자나 사람 승인 기록이 아니다.

대표 확인:

- `(3x²)(-2x³)=-6x⁵`; 계수 곱과 지수 합을 분리한다.
- `12a⁵b² ÷ 3a²b`에서 a의 지수는 `5-2=3`이다.
- `(3x²+2x-1)+(x²-4x+5)`의 상수항은 `-1+5=4`이다.
- `-2a(3a-5)`에서 a항은 `+10a`이다.
- `x=4`를 `2(x+4)=18`에 대입하면 왼쪽은 16이어서 해가 아니다.

정답과 해설은 별도 `proposal-preview` 평가 은행에만 있고 전체 제출 전 공개 DTO에는 포함되지 않는다. 전체 결과를 자동 검증한 뒤에도 사람 검수 전에는 production 공개할 수 없다.
