# M3-02 조사·문항 초안 보고

- 단원: 다항식의 곱셈 확장 (세 항의 전개, 대칭식의 전개)
- 명세 참조: `docs/specifications/NEXT_BATCH/M3-02/lesson-spec.json`, 버전 `0.1.0-draft`; 제안 선수 단원 M3-01, M2-09.
- 공식 자료 확인: 교육부 고시 제2022-33호 페이지를 2026-11-02에 확인했다. 페이지는 2022-12-22 고시와 수학과 별책 8을 명시한다. 별책8 첨부 본문에서 이 제안 단원의 성취기준을 직접 매핑하지 않았으므로 코드·문구 매핑은 미검증이다.
- 권리: 외부 기출·교재·공식 문구를 복사하지 않은 자체 제작 초안. 첨부 원문의 라이선스/재사용 조건은 별도로 확인하지 않았다.
- 문제: 자체 제작 연습 초안 6개, 사고 구조가 다른 원형 2개. 모든 문항 `draft`, humanVerified=false, 사람 승인 0, 평가 문항 없음.
- 계산: 정답·풀이를 작성자 자체 대조했다. 이는 독립적인 사람 수학 검토가 아니다.
- 구현 인계: `polynomial-multiplication` 인터랙션은 현재 앱 계약에서 지원되지 않아 Developer가 계약·렌더러·접근성 조작을 구현해야 한다. 운영 curriculum이나 평가·숙달도 경계에는 넣지 않는다.
- 미해결: 문항 원형의 독립성과 난이도는 교육 전문가·사람 검수 전이다. 공식 성취기준 매핑 및 콘텐츠 게시 승인도 대기한다.

- 교차 검토 반영: 제안된 대칭식 전개는 완전제곱식·합차 곱의 특수 공식 범위로 한정하고 일반 대칭다항식과 구분했다.

- Curriculum workedExample의 문제 문구·정답·풀이 순서와 화면용 WorkedExampleBlock을 일치시켰다. 교차 검토 후 자체 정답 대조를 갱신했으며 사람 검수/승인은 여전히 없다.
