# M2-02 자료조사·문항 초안 보고

- 상태: 자료 목록 확인·자체 제작 초안 / 독립 검수 대기
- 공식 자료 출발점: [교육부 2022 개정 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=%29), [NCIC 수학과 교육과정 별책 8 검색](https://ncic.re.kr/srch/result_more.do?cate=attach&order=desc&page=2&search=2022+%EA%B0%9C%EC%A0%95&sort=date). 공식 코드와 이 제안 단원 간 매핑은 확인하지 않았음.
- 자체 제작 문항 6개, 사고 원형 2개. 숫자만 바뀐 문항을 새 원형으로 세지 않음.
- 저작권: 외부 기출·교재 문항 복제 없음; 자체 제작 초안.
- 수학 확인: 작성자 정의·계산 자체 점검; 독립 사람 검수 0, 승인 0, 게시 0.
- 오개념 가설은 문제 원형 데이터에 기록.
