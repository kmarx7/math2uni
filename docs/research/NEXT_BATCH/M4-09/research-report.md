# M4-09 자료조사 상태 기록

- 제안 단원명: 집합의 표현과 포함
- 공식 배경 확인: 2026-11-04 교육부 고시 페이지에서 수학과 교육과정 별책 8 표기를 확인했다. 별책 원문을 조항별로 대조하지 않았으므로 이 단원 및 공식 성취기준 코드에 매핑하지 않는다.
- 수능 맥락: 교육부의 2028 통합형 수능 확정 보도자료에서 선택과목 없는 체제와 심화수학 제외 문구를 확인했다. 이 단원이 직접 출제된다는 판단은 하지 않는다.
- 교수법·오개념: 단원 특정 실증 근거와 오개념 빈도는 확인되지 않았다. 문항에 쓸 오개념은 가설로 표시한다.
- 교육과정 명세: `docs/specifications/NEXT_BATCH/M4-09/lesson-spec.json`을 확인했다. 목표 기술은 `m4-09-skill-1`, `m4-09-skill-2`, 계획된 실험실 ID는 `m4-09-lab`이다.
- 문항 상태: `problem-blueprint.json`에 서로 다른 추론 가족 3개와 자체 제작 연습 초안 6개를 작성했다. 모든 답과 풀이를 작성자가 손으로 재확인했고 Curriculum 독립 에이전트가 6개 답 키를 재계산해 모두 일치함을 확인했다. 이는 에이전트 수준 검토이며 사람 검수/게시 승인이 아니다. 형성평가 인스턴스는 만들지 않았다.
- 렌더러 초안: `src/data/proposal-lessons/drafts/M4-09.json`에 명세 6개 소단원과 15개 학습 단계를 반영한다. `m4-09-lab`은 현재 enum의 `condition-map`에 임시 대응한다. Venn diagram 전용 렌더링 및 접근성 조작은 구현/QA 전이다.
- 권리: 외부 기출·교재 문항을 사용하거나 복제하지 않는다. 자체 창작 연습 초안만 만들며 사람 검수 전 draft로 유지한다.
