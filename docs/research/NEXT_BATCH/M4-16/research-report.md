- 권리: 외부 기출·교재·예시문항을 복제하거나 변형하지 않았다. 후속 초안은 자체 제작으로 구분하고 출처·이용 조건을 별도로 기록한다.
- 검토 상태: 자료조사 초안. 공식 코드/매핑 미검증, 사람 검수 대기. 조사 완료는 문항 승인이나 게시 승인이 아니다.
- 출처와 확인 제한: `sources.json` 참조.

## 교수·정확성 확인 메모

(f∘g)(x)=f(g(x))로 안쪽 g가 먼저 적용된다. 합성 정의역은 x가 g의 정의역에 있고 g(x)가 f의 정의역에 있는 경우로 제한한다.

- 제안 개념에서 흔히 발생한다고 실증된 빈도 주장이 아니라, 후속 초안/피드백에서 검토할 후보만 적는다.

- 문제를 만들 때 적용 조건, 정의역, 등호 조건과 유일 정답을 별도로 계산 검증한다.
