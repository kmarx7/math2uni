# M3-12 조사 및 문항 초안 보고

- 단원: 이차방정식과 이차함수
- 명세: `docs/specifications/NEXT_BATCH/M3-12/lesson-spec.json` (0.1.0-draft)
- 학습 초안: `src/data/proposal-lessons/drafts/M3-12.json`; 여섯 개념 설명·활동·확인, 접근 가능한 실험실 인계, 단계별 예제, 오답·복습 골격을 작성했습니다.
- 문항: 자체 제작 연습 초안 6개, 서로 다른 추론 구조의 원형 3개(각 2개). 모두 draft, humanVerified=false, publicationApproved=false이며 평가 문항은 없습니다.
- 정답: 정의와 계산에 따른 작성자 자체 검산이며 독립 사람 검토가 아닙니다. 자동 채점 형식은 정수/분수 기반의 범위 내 답안입니다.
- 권리: 외부 기출이나 교재 문항을 복제하지 않았고, 초안은 자체 작성했습니다.
- 자료 조사: 교육부 발표 페이지는 직접 확인해 교육과정 맥락만 확인했습니다. NCIC 고시 안내는 공식 사이트 검색 결과에서 찾았지만 직접 URL 요청이 이 환경에서 404로 실패해 페이지 확인으로 취급하지 않습니다. 단원별 공식 성취기준 연결은 확인하지 않아 `unverified`로 남겼습니다.
- 교수법/오개념: 구체적 오개념 진술과 활동은 작성자 가설입니다. 해당 단원에 대한 학생 집단 빈도나 수업 효과를 검증하는 독립 자료는 확보하지 못했습니다. 검증된 연구 결과로 읽히지 않도록 했습니다.
- 구현 인계: 명세의 상호작용 ID `quadratic-intersection`를 사용합니다. 현재 Zod interaction enum에는 아직 없어 Developer가 계약을 확장한 뒤 실제 `contentSchema` 파싱을 재검증해야 합니다.
- 미해결: 문제 원형의 교육적 독립성, 난도·초보 학습자 적합성은 Curriculum 교차 검토 및 사람 검수 대기입니다.
