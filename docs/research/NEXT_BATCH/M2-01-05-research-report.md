공식 고시와 수학과 자료의 위치를 확인하는 출발점으로 기록했다. 각 제안 단원의 공식 성취기준 코드·문구는 독립적으로 대조하지 않았으며 `officialStandards`는 비워 둔다. 단원 제목·순서는 제공된 제안 메타데이터를 유지했다.

## 설계·문항

- M2-01은 두 식의 해집합이 만나는 순서쌍을 공통해로 설명한다.
- M2-02는 대입법과 가감법을 구분하고 원래 두 식에서 검산한다.
- M2-03은 두 미지수의 뜻·단위를 정한 뒤 수량/금액 조건을 각각 식으로 만든다.
- M2-04는 입력 하나에 출력 하나를 대응하는 함수와 `y=ax+b`의 표를 연결한다.
- M2-05는 기울기·y절편을 식과 그래프에서 읽는다.

자체 제작 연습 문항 초안 30개(단원당 6개)와 서로 다른 원형 10개를 설계했다. 외부 기출이나 교재 문항을 복제하지 않았다. 정답 계산은 작성자의 정의·계산 자체 점검을 거쳤지만 사람의 독립 수학·교육 검수는 0건이다. 모든 문항은 draft, 승인 0, 게시 0이다.
