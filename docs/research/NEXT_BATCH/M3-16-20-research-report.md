# M3-16~M3-20 자료조사 및 문항 초안 보고

## 자료 확인

- 교육부 고시 제2022-33호 공식 페이지를 직접 확인했다. 페이지에는 초·중등학교 교육과정 각론 첨부 ZIP이 있으며 파일명에 수학을 포함하는 별책 5~14 자료가 표시된다. 첨부 수학 원문을 성취기준 수준까지 대조하지 않았으므로 본 제안 단원과 공식 성취기준 코드의 연결은 `unverified`로 둔다.
- NCIC 공식 검색 결과/색인에서 2022 개정 고시와 수학과 별책 8을 확인했다. 과거 상세 URL의 직접 접근은 404였으며 첨부 원문을 확인한 것으로 간주하지 않는다.
- 교육부의 2028 통합형 수능 확정 안내와 과목 체제 Q&A를 확인했다. 이 자료는 시험 체제 배경일 뿐 M3-16~20이 수능 직접 출제 범위라는 근거가 아니다.
- URL, 확인 상태, 권리 및 사용 범위는 `M3-16-20-sources.json`에 기록했다. 출처 자료의 본문과 문항을 재배포하지 않는다.

## 교육·문항 설계 한계

단원별 오개념 빈도나 특정 교수법의 효과를 검증한 독립 연구 자료는 확보하지 못했다. 각 문항의 오개념 설명은 작성자 가설이며 검증된 빈도처럼 표현하지 않는다. 모든 문항은 자체 작성 초안이다.

## 문항·콘텐츠 상태

M3-16~20 각 단원은 명세의 `questionBlueprint`에 맞춰 서로 다른 추론 구조의 문제 원형 3개와 연습 문항 6개를 가진다. 문항 정답은 작성자가 계산·정의·조건을 이용해 자체 검산했지만 독립 사람 검수는 아니다. 모든 초안은 `draft`, `humanVerified=false`, `publicationApproved=false`로 유지하며 평가 문항은 없다.

Renderer 학습 데이터는 `src/data/proposal-lessons/drafts/M3-16.json`~`M3-20.json`에 작성했다. 인터랙션은 lesson spec ID에 연결되며 UI 연결·런타임 계약 적합성은 Developer QA가 확인해야 한다.
