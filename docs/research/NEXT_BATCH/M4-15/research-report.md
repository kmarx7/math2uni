# M4-15 자료조사 상태 기록

- 제안 단원명: 함수와 그래프
- 제안 선수 단원(메타데이터 변경 없음): M2-04, M4-09
- 검토 주제: 정의역과 치역, 함수의 대응 조건
- 공식 자료: 교육부 2022 개정 고시에서 수학과 별책 8 게시를 확인했고 NCIC 카탈로그에도 별책8 첨부가 표시된다. 2026-1 일부개정 고시의 목록은 별책 1~4,15이며 별책8을 포함하지 않는다. 다만 수학과 별책 원문 조항을 확인하지 않았으므로 이 단원이나 공식 성취기준 코드에 매핑하지 않는다.
- 2028 수능 맥락: 교육부 통합형 수능 확정 및 예시문항 안내 페이지를 확인했다. 이는 제도 배경이며 이 단원의 직접 출제·필수 여부를 확인하거나 추론한 것이 아니다. 예시문항 PDF는 열어 분석하거나 재사용하지 않았다.
- 교수법·오개념 근거: 단원 특정 효과 연구와 오개념 빈도를 직접 확인하지 않았다. 아래 주제와 오개념은 수학적 점검에서 나온 **설계 가설**이며 검증된 연구 결과가 아니다.
- 권리: 외부 기출·교재·예시문항을 복제하거나 변형하지 않았다. 후속 초안은 자체 제작으로 구분하고 출처·이용 조건을 별도로 기록한다.
- 검토 상태: 자료조사 초안. 공식 코드/매핑 미검증, 사람 검수 대기. 조사 완료는 문항 승인이나 게시 승인이 아니다.
- 출처와 확인 제한: `sources.json` 참조.

## 교수·정확성 확인 메모

관계와 함수를 구별하고, 함수는 각 정의역 원소가 정확히 한 출력에 대응해야 한다. 공역과 치역을 혼동하지 않게 유한 대응표부터 다룬다.

## 오개념 후보 (설계 가설)

- 제안 개념에서 흔히 발생한다고 실증된 빈도 주장이 아니라, 후속 초안/피드백에서 검토할 후보만 적는다.
- 정의역·조건·기호 순서를 생략하거나 몇 사례만으로 일반 명제를 증명했다고 오해할 수 있다. 실제 학생 빈도 자료로 표현하지 않는다.
- 문제를 만들 때 적용 조건, 정의역, 등호 조건과 유일 정답을 별도로 계산 검증한다.

## 다음 단계 인계

Curriculum Architect의 단원 명세와 대조해 문제 원형과 콘텐츠 초안을 작성했다. 원문 성취기준을 직접 검토하기 전까지 `officialStandards: []`를 유지한다. 자체 제작 문항은 `draft`, `humanVerified:false`, `publicationApproved:false`이며 숫자만 바꾼 인스턴스는 새 원형으로 세지 않는다.
- 문항 초안: `problem-blueprint.json`에 서로 다른 사고구조 3개와 자체 제작 선택형 연습 초안 6개를 작성자 계산으로 점검해 저장했다. 함수 여부는 정의역 각 입력의 출력 개수로 판단하며, 치역은 실제 출력만 중복 없이 모아 확인한다. 평가 문항은 없다.
- lesson renderer: 명세의 6개 소단원과 15단계를 초안 JSON에 연결했다. `function-mapping`은 기존 interaction enum의 임시 대응이며 전용 실험실 구현 전이다.
- 검수 상태: 작성자 자체 계산만 완료. Curriculum 독립 재계산과 사람 검수/게시 승인이 남아 있고, 모든 문항은 draft·humanVerified=false·publicationApproved=false다.

## 정답 검증 상태 갱신

Curriculum 독립 AI 리뷰가 현재 blueprint의 6개 답안 키와 해설을 모두 재계산해 일치(6/6)함을 확인했다. 이 표시는 자동/AI 검토 상태이며 사람 수학·교육 검수나 게시 승인으로 보지 않는다. 개별 문항 `status=draft`, `humanVerified=false`, blueprint `publicationApproved=false`를 유지한다.
