# M4-08 자료조사 상태 기록

- 단원명(제안 커리큘럼): 도형의 대칭이동
- 작업 전달 메타데이터: `src/data/proposals/units.json`의 제안 개념·선수 단원·시각화
- 교육과정 명세: `docs/specifications/NEXT_BATCH/M4-08/lesson-spec.json`을 확인했고 목표·선수 기술·소단원에 맞춰 초안을 반영했다.
- 공식 코드/매핑: 미확정. 교육부 고시 페이지에서 수학과 교육과정 첨부(별책 8)의 존재를 확인했지만, 첨부 원문을 조항별로 대조하지 않았다. 이 제안 단원이나 공식 성취기준 코드를 추측하지 않는다.
- 2028 수능 맥락: 교육부의 통합형 수능 개편 페이지를 정책 배경으로만 확인했다. M4-04~08이 직접 출제 범위라는 결론은 내리지 않는다.
- 교수법 및 오개념: 단원별 경험적 연구나 오개념 빈도를 검증하지 않았다. 이후 문제의 오개념 설명은 설계 가설로 표시한다.
- 문항·권리: 외부 기출/교재 문항을 복제하지 않고 자체 제작한 연습 초안 6개를 작성했다. 답과 풀이를 작성자가 계산했고 Curriculum 독립 에이전트의 재계산도 완료했다. 사람의 수학·교육 검수와 게시 승인은 대기 중이다. 문항은 사람 검수 전 draft로 유지한다.
- 출처/이용 상태: `sources.json` 참조. 공식 자료는 출처 표기와 맥락 확인에만 사용하며, 제3자 문항은 수집·재배포하지 않는다.
- 상태: researched; 문제 청사진 및 renderer draft 작성 완료. Curriculum 독립 에이전트 검토는 완료했으나, 사람의 검수·게시 승인과 공식 매핑 확인은 대기 중이다.


## 문항·인터랙션 인계

- 청사진: `problem-blueprint.json`; 서로 다른 추론 가족 3개, 연습 초안 6개, 평가 0개.
- 렌더러: `src/data/proposal-lessons/drafts/M4-08.json`; 명세의 6개 소단원과 15단계를 반영.
- 문항은 자체 제작, 답·풀이 작성자 재계산 상태이며 모두 draft, `humanVerified=false`, 게시 승인=false. 독립 검토자는 별도로 재계산해야 한다.
- 실제 명세 interaction ID `m4-08-lab`를 현재 `contentSchema` enum `coordinate-plane`에 임시 매핑했다. 이는 전용 조작 구현을 뜻하지 않으며 개발/QA에서 단원별 라우팅을 보완해야 한다.
- 외부 기출/교재는 복제하지 않았다. 공식 매핑·교수법 효과·오개념 빈도는 미검증이다.
