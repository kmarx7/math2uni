# M4-03 자료조사 상태 기록

- 단원명(제안 커리큘럼): 두 직선의 위치 관계
- 개념 초점(작업 전달 메타데이터): 평행 조건·수직 조건
- 교육과정 명세: `docs/specifications/NEXT_BATCH/M4-03/lesson-spec.json` 수령 후 목표·선수 개념·소단원과 문제 기술을 대조해 초안에 반영했다.
- 공식 코드/매핑: 미확정. 공식 고시 페이지를 찾았으나 첨부 수학과 교육과정을 조항별 대조하지 않았다. 임의 코드를 만들거나 시험 범위를 추정하지 않는다.
- 조사 범위: 평행·수직 판정의 교육과정 코드 및 세부 범위는 미확정. 기울기 비교에서 수직선 예외를 다루는 정확성 위험을 기록한다.
- 교수법 및 오개념: 단원별 경험적 연구를 검증하지 않았다. 추후 문항의 오개념 표기는 가설로만 둔다.
- 문항·권리: 외부 기출/교재 문항을 복제하지 않은 자체 초안이다. 답은 조건에서 계산해 draft로 유지하며, 독립 검토가 끝나지 않았다.
- 출처/이용 상태: `sources.json` 참조. 공식 자료는 배경 맥락에만 사용했고, 제3자 문항은 수집·재배포하지 않았다.
- 상태: researched; problem blueprint 및 renderer draft 작성 완료. 독립 검토와 사람 공개 승인은 대기 중이다.

## 문항 원형 및 콘텐츠 초안 인계

- 청사진: `problem-blueprint.json` — 독립적인 추론 가족 3개, 자체 연습 초안 6개, 평가 문항 0개.
- 렌더러 자료: `src/data/proposal-lessons/drafts/M4-03.json` — 명세의 목표·선수 개념·소단원·15단계 흐름을 반영.
- 각 문항은 답과 풀이를 작성자가 별도로 다시 계산했으며 결과는 `author-self-check-only`; 사람 검수는 대기 중입니다. `humanVerified=false`, 공개 승인=false, 상태 draft.
- 권리: 전 문항은 프로젝트 자체 초안이며 외부 기출·교재 문항을 복제하지 않았습니다.
- 인터랙션: renderer contract에서 현재 지원되는 `line-intersection` 표현을 사용했습니다. 명세의 전용 상호작용 ID `m4-03-lab`는 데이터에 표시했으나, 전용 조작 기능은 구현/검수 전입니다.

### 인터랙션 계약 대조

- 명세 컴포넌트 ID: `m4-03-lab`; 목표: 기울기 쌍 비교.
- 현재 `contentSchema`가 허용하는 미리보기 대응 enum: `line-intersection`.
- 한계: 두 직선 관계 표현에 부분 대응. 기울기 곱과 수평/수직 예외를 안내하는 전용 제어는 미구현.
- 따라서 명세 컴포넌트 자체의 기능이 구현됐다고 주장하지 않으며, 대응 enum으로 표시된 시각화 초안입니다.

### 독립 검토 피드백 반영

- Curriculum Architect의 초도 교차 검토에서 발견된 답 키 또는 기술 ID를 수정했습니다: m403p03 C→A.
- 수정 뒤 수식/조건을 다시 계산했습니다. 검토 보고서 최종 판정은 대기 중이며, `humanVerified=false` 및 게시 승인=false를 유지합니다.
