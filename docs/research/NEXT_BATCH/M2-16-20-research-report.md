# M2-16~M2-20 자료조사 및 문항 초안 보고

- 범위: 피타고라스 정리, 삼각비의 기초, 원과 삼각형의 성질, 산포도와 산점도, 중학 수학 연결 점검.
- 문항: 단원별 자체 제작 연습 초안 6개, 문제 원형 2개(총 30개 초안). 평가 문항은 포함하지 않는다.
- 근거: 각 단원별 `M2-16/`~`M2-20/`의 research-report.md 및 problem-blueprint.json에 개념 범위·문항 근거를 기록했다. 참고 링크는 조사 초안에 기록했으며 이번 통합 과정에서 원문을 재열람하지 않았다.
- 권리: 외부 기출·교재 문항을 복사하지 않은 자체 제작 초안으로 기록한다.
- 검증 상태: 답과 풀이의 자동/작성자 점검은 테스트 결과와 별도 기록한다. 독립적인 사람 검수 0, 게시 승인 0. 공식 성취기준 코드 매핑은 미검증.
