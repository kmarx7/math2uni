# 170단원 단계별 완성 계획

## 목표와 현재 단계

2026-11-01 사용자 요청: “단계별로 170단원까지 완성을 하기 시작”. 한 번에 이름만 채운 170페이지를 만드는 대신 학습·연습·형성평가·오답·복습·계정 저장·단원 이동을 검증한 묶음으로 확장한다. 모든 단계에서 실제 성적을 보장하지 않는다.

1단계 **LEVEL 0의 기존 12개 ID에 대한 콘텐츠 초안 구현**을 마쳤고, 현재는 **2단계 170단원 전체 제안안 작성 및 검토 준비**이다. 원래 M0-01만 가능했던 학습 화면을 M0-01~M0-12로 확장한다. 이는 마스터 170단원 정본이 승인되었다는 뜻도, 사람 검수가 끝나 운영 공개할 수 있다는 뜻도 아니다.

## 1단계 구현 명세

- 12개 단원 각각 목표·선수 자기 점검·개념·조작·단계별 예제·독립 연습·오개념·형성평가·복습을 가진다. 내용이 다른 단원별 데이터와 공통 렌더러를 사용한다.
- M0-01의 기존 ID/문항/계정 기록을 보존한다. 새 단원에도 동일한 블록 ID가 있으므로 진도는 unitProgress[unitId]로 격리한다. 기존 루트 진도/점수는 M0-01에만 대응한다.
- 평가용 문항은 unitId로 분리하고 서버에서만 채점한다. 다른 단원의 응답 집합을 보내도 평가가 완료되지 않는다.
- 신규 문항은 자동 정합성 검사 상태(reviewed)이다. 개발 검토 모드에서만 제공하며 사람 승인 전 production 공개를 차단한다.
- 단원마다 세 전략을 연결한다. 종합 점검의 세 전략은 기존 원형을 재사용한다. 숫자만 바꾼 문항이나 종합 재출제를 새로운 원형으로 부풀리지 않는다. 현재 원형 ID는 총 33개이다.
- 덧셈·곱셈·나눗셈·계산 순서·약수·분수·소수·비율·음수에 맞는 bounded 조작 도구를 사용한다.
- 다음 단원 링크는 해당 단원 완료 조건 충족 시 표시한다. 선수 개념 미숙은 해당 단원 복습 링크로 안내한다. LEVEL 0의 마지막은 아직 등록되지 않은 LEVEL 1로 자동 진행하지 않는다.

## 검수 및 자료 의존성

현재 LEVEL 0 목록은 초기 편집 초안이다. 원본 170단원 정본 목록은 아직 제공되지 않았다. 기존 목록과 충돌하는 내용이 생기면 마음대로 ID를 바꾸지 않고 검토 절차를 거친다. 정확한 전체 목록을 확보하기 전 `curriculum:canonical`은 계속 실패한다. 전체 170단원 완료로 보고하지 않는다.

수치 정답의 자동 재계산은 전문가의 설명·용어·교육적 적합성 검토를 대체하지 않는다. LEVEL 0의 D1~D3 기본 묶음부터 확인하고 학습자의 오답과 복습 기록을 바탕으로 유형/난이도를 확장한다.

## 2단계 결과 · 구성 검토 준비

원본 목록은 아직 없으므로 170개 정본으로 등록하지 않았다. 기존 12개를 보존한 [170단원 제안안](CURRICULUM_PROPOSAL.md), 신규 158단원 메타데이터와 자동 검사, 로그인 후 `/curriculum/plan` 읽기 전용 검토 화면을 작성했다. LEVEL별 수량은 12/20/20/22/20/24/24/20/8이다. 검색·상세·선수 연결·JSON 내려받기가 가능하다.

다음 구현 묶음은 제안 M1-01~M1-05(정수·유리수·기초 지수법칙·문자 대입)이다. 전체 구성 확인과 범위 검토 후 제안 ID/순서를 확정한다. 이 단계의 종료 상태는 **제안안 구현 완료 / 구성 확정 대기**이며 본문·문항은 기존 12개 단원에만 있다. 구성 확정과 사람의 문항 게시 승인을 동일시하지 않는다.
