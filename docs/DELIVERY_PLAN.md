# 170단원 단계별 완성 계획

## 목표와 현재 단계

2026-11-01 사용자 요청: “단계별로 170단원까지 완성을 하기 시작”. 한 번에 이름만 채운 170페이지를 만드는 대신 학습·연습·형성평가·오답·복습·계정 저장·단원 이동을 검증한 묶음으로 확장한다. 모든 단계에서 실제 성적을 보장하지 않는다.

1단계 **LEVEL 0의 기존 12개 ID에 대한 콘텐츠 초안 구현**과 2단계 **Math 90 제안 경로 설계 결정**을 마쳤다. 현재는 3단계로 M1~M8의 제안 단원을 묶음별로 개발 프리뷰에 추가 중이다. 앞서 연결된 65개에 M4-04~08 다섯 단원을 더해 총 70/158개가 등록됐고 88개가 남았다. 이번 배치 QA는 [M4-04~08 batch QA](reviews/NEXT_STEP/M4-04-M4-08-batch-qa.md)에 기록한다. 콘텐츠는 개발 프리뷰이며 E2E는 테스트 서버의 `127.0.0.1:54329` bind에서 `EPERM`으로 시작하지 못해 미검증이다. 경로 수량은 사용자 기준 `12/14/18/22/24/20/22/18/20`으로 고정했지만, 이는 공식 정본·콘텐츠 게시 승인과 구분된다.

## 1단계 구현 명세

- 12개 단원 각각 목표·선수 자기 점검·개념·조작·단계별 예제·독립 연습·오개념·형성평가·복습을 가진다. 내용이 다른 단원별 데이터와 공통 렌더러를 사용한다.
- M0-01의 기존 ID/문항/계정 기록을 보존한다. 새 단원에도 동일한 블록 ID가 있으므로 진도는 unitProgress[unitId]로 격리한다. 기존 루트 진도/점수는 M0-01에만 대응한다.
- 평가용 문항은 unitId로 분리하고 서버에서만 채점한다. 다른 단원의 응답 집합을 보내도 평가가 완료되지 않는다.
- 신규 문항은 자동 정합성 검사 상태(reviewed)이다. 개발 검토 모드에서만 제공하며 사람 승인 전 production 공개를 차단한다.
- 단원마다 세 전략을 연결한다. 종합 점검의 세 전략은 기존 원형을 재사용한다. 숫자만 바꾼 문항이나 종합 재출제를 새로운 원형으로 부풀리지 않는다. 현재 원형 ID는 총 33개이다.
- 덧셈·곱셈·나눗셈·계산 순서·약수·분수·소수·비율·음수에 맞는 bounded 조작 도구를 사용한다.
- 다음 단원 링크는 해당 단원 완료 조건 충족 시 표시한다. 선수 개념 미숙은 해당 단원 복습 링크로 안내한다. LEVEL 0의 마지막은 아직 등록되지 않은 LEVEL 1로 자동 진행하지 않는다.

## 검수 및 자료 의존성

기존 M0-01~12와 M1~M8 제안 158개를 합친 내부 경로는 총 170개 ID와 사용자 지정 LEVEL 수량을 만족한다. 공식 원본 170단원 목록·성취기준은 제공/대조되지 않았으므로 canonical manifest는 비어 있고 `curriculum:canonical` 출시 게이트는 계속 실패한다. 기존 단원 ID·제목·역사적 분류와 사용자 진도는 변경하지 않았다.

수치 정답의 자동 재계산은 전문가의 설명·용어·교육적 적합성 검토를 대체하지 않는다. LEVEL 0의 D1~D3 기본 묶음부터 확인하고 학습자의 오답과 복습 기록을 바탕으로 유형/난이도를 확장한다.

## 2단계 결과 · Math 90 제안 경로 결정

원본 공식 목록이 없어 170개 정본으로 등록하지 않았다. 기존 M0 12개와 신규 제안 메타데이터 158개, 자동 검사와 로그인 후 `/curriculum/plan` 읽기 전용 화면을 마련했다. 원래 제안 v0.1.0의 역사적 `Unit.level/order` 분포는 보존하고, 새 제안 경로 v0.3.0에서 사용자 지정 수량 `12/14/18/22/24/20/22/18/20`으로 모든 ID를 한 번씩 배치했다.

경로 수량과 LEVEL 1·2 표시명은 ADR-007에 따라 Math 90 개발 기준으로 결정했다. LEVEL 8은 M7-19·M7-20을 첫 교수 후보로 포함한다. 기존 단원 ID·역사적 분류와 `canonicalManifest`는 바꾸지 않았다.

## 최신 경로 검토 및 다음 구현 단계

세 전문 에이전트의 실제 설정 발견·호출은 사용자가 새 로컬 Codex 세션에서 검증했다고 보고했다. 현재 CLI가 자동화 실행기 안에서 호출될 때는 app-server 권한 오류가 있었지만, 로컬 Codex에서는 세 역할이 모두 완료됐고 파일을 수정하지 않았다고 확인했다.

`learningPath` v0.3.0은 170개 ID의 일대일 대응, 고정 수량, 선수 순서, M7-19·M7-20의 LEVEL 8 첫 교수 분류를 검사한다. 교육부 원문과 공식 성취기준의 개별 대조, 사람 전문가 검수, 콘텐츠 게시 승인은 별도 게이트다. 자세한 경로와 위험 기록은 [마스터 학습 경로 결정안](reviews/NEXT_STEP/curriculum-path-proposal.md)을 본다.

다음 개발 묶음은 기존 순서를 지켜 M3-21~M3-22와 M4-01~M4-03을 계획한다. 단원 콘텐츠의 사람 검수와 경로 설계 결정은 별도 상태로 관리한다.

## M1-01~M1-05 · 검토용 첫 구현

2026-11-01 작업에서 M1-01 정수와 절댓값부터 M1-05 문자와 식의 값까지 교육 명세 5개, 문제 원형 10개, 자체 제작 연습 초안 30개를 만들고 공통 화면에 개발 전용 미리보기로 연결했다. 각 콘텐츠에는 6개 소단원/15단계 계획이 있고, 정수 수직선·부호 있는 곱셈·분수 조각·거듭제곱·식의 값 실험을 공통 렌더러에 추가했다. 로그인된 테스트 계정 진도는 `unitProgress[unitId]`로 저장되어 M0-01 루트 기록과 분리된다.

이 다섯 단원은 여전히 제안 상태다. 운영 curriculum, canonical manifest, 정본 학습 목록에는 추가하지 않았고 `npm run dev` 검토 모드에서만 열리며 production은 404/문제 비공개로 막는다. 문항은 모두 draft, 사람 승인 0개다. 구현된 문항은 연습용 30개이며 독립 형성평가 문항·다음 M1-06 이후 본문은 아직 없다. 형성평가와 공식 완료 판정도 UI에서 준비 중으로 표시한다. 상세 검토 및 QA 결과는 [M1 배치 리뷰](reviews/NEXT_BATCH/M1-batch-report.md)를 본다.

## M1-01~M1-10 · 다음 초안 묶음

2026-11-02에는 기존 제안 ID를 유지해 M1-06~M1-10을 공통 학습 화면의 개발 미리보기로 연결했다. 단항식·다항식·분배법칙·등식·일차방정식 콘텐츠 초안, 단원마다 6개 소단원과 15단계 계획, 조작형 실험실 5개를 추가했다. M1-06~M1-10 연습 초안 30개는 앞의 30개와 별도이며, 연습 원형은 총 20개다. M1-01~M1-05에는 단원별 3문항 형성평가 초안 15개를 별도 `proposal-preview` 문제 컬렉션으로 구현했다. 정답·해설은 전체 제출 후에만 반환한다.

새 M1 시도는 인증된 계정의 `unitProgress[unitId]`에 기록한다. `proposal-preview` 시도는 정본 숙달도·오답노트·복습 일정에 포함하지 않고 M0-01 루트 점수도 변경하지 않는다. 제안 ID 10개 모두 운영 curriculum과 canonical 목록 밖에 있으며 개발 preview allowlist에서만 접근할 수 있다. 문항 상태는 draft, 사람 수학·교육 검수 0건, 게시 승인 0건이다. M1-06~M1-10 형성평가는 아직 준비되지 않았다.

검증은 lint, typecheck, Vitest 107개, production build 통과다. `npm run test:e2e`는 테스트 서비스가 `127.0.0.1:54329`에 bind할 때 EPERM으로 시작하지 못해 이번 브라우저 흐름은 미검증이다. 세부 결과는 [M1 배치 2 QA](reviews/NEXT_BATCH/M1-batch-02-qa.md)를 본다.

## M1-06~M1-15 · 세 번째 개발 묶음

2026-11-02에는 M1-06~M1-10에 분리된 형성평가 초안 15개(3개씩)를 추가했다. M1-11~M1-15는 제안 ID와 선수 연결을 유지해 공통 화면에 등록했다. 각 신규 단원은 6개 소단원, 15단계 계획, 인터랙티브 수학 실험실, 2개 원형·6개 연습 초안을 제공한다. M1-11~15의 평가는 아직 준비되지 않았으므로 준비 중 상태를 유지한다. M1-01~15 연습 초안은 90개·30개 원형, 평가 초안은 M1-01~10의 30개다.

모든 초안은 기존 개발 preview allowlist에서만 접근한다. 계정별 단원 기록을 쓰지만 M0-01 루트 점수·블록 기록이나 공식 숙달·복습 경계에 합치지 않는다. 공식 교육과정 고시 자료의 별책 8 표시를 확인했으나 이 다섯 단원과 개별 성취기준 코드의 매핑은 확인되지 않아 미기재했다. 자료 출처·확인 상태는 [조사 보고](research/NEXT_BATCH/M1-11-15-research-report.md)에 남겼다.

검증: lint, typecheck, Vitest 107개, content:validate 18개, build 통과. `npm run test:e2e`는 test auth service가 `127.0.0.1:54329`에 bind할 때 EPERM으로 시작하지 못해 브라우저 플로우는 미검증이다. [M1 배치 3 QA](reviews/NEXT_BATCH/M1-batch-03-qa.md)를 참고한다.

## M1-16~M1-20 · 네 번째 개발 묶음

2026-11-02에는 제안된 M1-16~M1-20(삼각형과 다각형, 평면도형의 넓이, 입체도형과 부피, 자료의 정리와 대표값, 수와 식 기초 종합)을 개발 미리보기로 구현했다. 각 단원은 6개 소단원, 15개 학습 단계, 별도 인터랙티브 활동, 서로 다른 2개 문제 원형과 연습 문항 6개를 갖는다. M1-16~20에서 추가된 연습 초안은 30개이며, M1-01~20 전체 미리보기에는 120개 연습 초안과 40개 문제 원형이 있다. M1-11 이후 단원에 새 평가 문항은 추가하지 않았다.

새 콘텐츠와 문제는 모두 draft이며 자동 스키마·정답 계약 검사만 통과했다. 사람의 교육·수학 검수와 게시 승인은 0건이다. 공식 교육 자료의 별책 8 위치와 원문 접근 경로를 확인했으나 이 제안 단원의 공식 성취기준과 개별 매핑은 검증하지 않았다. 기존 제안 ID·선수 단원·운영 진도·채점 경계는 그대로 두고 개발 preview manifest에만 추가했다. 상세요약은 [조사 보고](research/NEXT_BATCH/M1-16-20-research-report.md)와 [배치 4 QA](reviews/NEXT_BATCH/M1-batch-04-qa.md)에 남겼다.
