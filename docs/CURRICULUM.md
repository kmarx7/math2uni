# 교육과정 계약

## 정본의 상태

목표는 LEVEL 0~8 / 170단원이다. 공식 정본 170개 목록과 단원별 성취기준은 아직 제공·검증되지 않았으므로 데이터 coverage는 partial이고 canonicalManifest는 비어 있다. 기존 LEVEL 0 12개 ID와 제안 단원 M1~M8 158개 ID를 담은 Math 90 경로 v0.3.0은 별도 설계 계층에서 사용자 목표 수량 `12/14/18/22/24/20/22/18/20`에 맞춰 정리했다. 이 경로 결정은 공식 정본 등록이나 콘텐츠 게시 승인이 아니다. 기존 `Unit.level/order`, 단원명, ID는 그대로 보존한다.

## Unit 스키마

id(M[0-8]-NN), level(0~8), order(전체 고정 순서), title, status(draft/published), objectives[], concepts[{id,label}], prerequisites[](개념 ID), visualization[], problemTypes[], assessmentPlan, standards[{authority,code,sourceUrl,verifiedAt}] 및 version을 가진다. 공식 코드 연결은 근거를 검증한 뒤에만 작성한다. 현재 standards는 전부 빈 배열이다. 선수학습은 단원 순서와 별개로 개념에 연결한다.

## 검증

런타임 스키마, 단원/개념 ID와 순서 중복, ID-레벨 일치, 빠진 순번, 누락된 선수개념, 자기 의존 및 선수 그래프 순환을 검사한다. partial 검사는 등록 데이터의 무결성만 보증한다. 고정 registeredManifest와 비교하여 마지막 단원의 삭제나 ID 대체도 검출한다. canonical 검사는 170개 정본 manifest가 없거나 정확히 일치하지 않으면 오류를 반환한다. `npm run curriculum:canonical`은 정본 미제공 상태에서 의도적으로 exit 1이며 출시 게이트다. 이것을 170단원 완료 테스트로 보고하지 않는다.

## M0-01

목표: 0의 자리 유지 역할을 설명하고 네 자리 이하 자연수의 자리/숫자/자릿값을 구분하며 수를 분해·합성한다. 선수 진단은 1~9 세기와 십 묶음에 대한 자기 점검이며 (정답률 기반 진단은 후속 범위), 미숙하면 같은 단원 기초 블록으로 돌아간다. 자연수는 이 콘텐츠에서 1,2,3,…로 정의하며 0은 자연수의 자리를 채우는 숫자로 다룬다. 0 포함 여부의 관례 차이는 명시한다.

자리표 조작 → 예제 → 3개 풀이 원형의 연습 → 별도 평가 3문항 → 오답 피드백 → 다음 날 복습. D1 식별, D2 분해, D3 역추론을 제공한다. D4·D5는 계약만 지원하며 공개 문항은 없다. 평가 점수만으로 완료하지 않고 학습 블록 확인+세 개념 모두 숙달+평가 80% 이상을 함께 요구한다. 완료 조건 충족 시 다음 M0-02 학습 링크를 표시한다.

## LEVEL 0 확장 · 1단계

기존 M0-01~M0-12 ID/순서/제목을 보존했다. `level-zero-units.ts`가 M0-02~12의 목표·개념·설명·예제·힌트·오개념·조작 데이터를 제공한다. 각 단원은 세 개념과 연습/평가를 가진다. 선수 개념은 직전 단원 전체에 일괄 연결하지 않고 분수의 동치·공배수·자리값 등 실제 필요한 개념 ID를 명시한다. 그래프 검사가 누락/순환을 검증한다.

`published`는 공통 학습 라우트의 등록 상태이다. 콘텐츠의 사람 승인 상태는 별도 문항 게이트가 관리하며 현재 12개 모두 편집 초안이다. 신규 문항도 사람 승인 전 production에서 차단된다. 12개 콘텐츠 구현을 170단원 정본 완성으로 집계하지 않는다. 후속 묶음과 정본 승인 조건은 [DELIVERY_PLAN.md](DELIVERY_PLAN.md)를 따른다.

## 확정된 Math 90 제안 경로 · 공식 검증 별도

[전체 제안안](CURRICULUM_PROPOSAL.md)은 기존 ID/LEVEL/순서를 보존하는 v0.1.0 메타데이터와 최신 `learningPath` v0.3.0을 함께 설명한다. Math 90 개발 경로의 고정 수량은 `12/14/18/22/24/20/22/18/20`이다. LEVEL 1·2 표시명은 실제 배치 범위에 맞게 확장했고 M7-19·M7-20은 LEVEL 8 첫 두 교수 후보로 분류한다. 이 결정은 제안 경로의 구현 기준이며 공식 편성·수능 직접 출제 여부를 확정하지 않는다. [ADR-007](decisions/007-level-allocation.md)과 [경로 결정안](reviews/NEXT_STEP/curriculum-path-proposal.md)에 근거와 한계를 기록했다.

로그인 후 `/curriculum/plan`에서 사용자 기준 수량과 고정 개발 경로를 비교하고 단원별 목표·개념·선수 관계·시각화·평가 계획을 검토할 수 있다. LEVEL 필터는 별도 제안 경로를 따르며 각 카드에 기존 분류와 경로 위치를 나눠 표시한다. JSON 내보내기에도 경로가 포함된다. 화면은 읽기 전용이며 단원/문항 승인이나 진도를 변경하지 않는다. 검증기는 170개 ID의 일대일 대응, 고정 LEVEL 수량/표시명, 순서, 선수 관계, M7-19·M7-20의 첫 교수 위치를 확인한다. 운영 curriculum에는 기존 12개 단원만 등록되어 있다. 제안 단원 158개 중 60개는 개발 preview에 연결됐고 98개는 아직 미구현이다. 공식 성취기준·사람 검수·게시 승인 전까지 canonical 게이트는 미통과 상태로 유지한다.
