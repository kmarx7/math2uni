# 교육과정 계약

## 정본의 상태
목표는 LEVEL 0~8 / 170단원이다. 정본 170개 목록·LEVEL별 수량·순서가 제공되지 않았다. 따라서 데이터의 coverage는 partial이고 canonicalManifest는 비어 있다. 제공되지 않은 158개 단원을 이름만 채워 넣지 않는다. LEVEL 0 12개 항목은 제안 초안이며 M0-01만 학습 가능하다. 이후 정본과 대조하여 승인한 뒤 ID/학습 순서를 동결한다. UI도 전체 170개 완성으로 표현하지 않는다.

## Unit 스키마
id(M[0-8]-NN), level(0~8), order(전체 고정 순서), title, status(draft/published), objectives[], concepts[{id,label}], prerequisites[](개념 ID), visualization[], problemTypes[], assessmentPlan, standards[{authority,code,sourceUrl,verifiedAt}] 및 version을 가진다. 공식 코드 연결은 근거를 검증한 뒤에만 작성한다. 현재 standards는 전부 빈 배열이다. 선수학습은 단원 순서와 별개로 개념에 연결한다.

## 검증
런타임 스키마, 단원/개념 ID와 순서 중복, ID-레벨 일치, 빠진 순번, 누락된 선수개념, 자기 의존 및 선수 그래프 순환을 검사한다. partial 검사는 등록 데이터의 무결성만 보증한다. canonical 검사는 170개 정본 manifest가 없거나 정확히 일치하지 않으면 오류를 반환한다. `npm run curriculum:canonical`은 정본 미제공 상태에서 의도적으로 exit 1이며 출시 게이트다. 이것을 170단원 완료 테스트로 보고하지 않는다.

## M0-01
목표: 0의 자리 유지 역할을 설명하고 네 자리 이하 자연수의 자리/숫자/자릿값을 구분하며 수를 분해·합성한다. 선수 진단은 1~9 세기와 십 묶음이며, 미숙하면 같은 단원 기초 블록으로 돌아간다. 자연수는 이 콘텐츠에서 1,2,3,…로 정의하며 0은 자연수의 자리를 채우는 숫자로 다룬다. 0 포함 여부의 관례 차이는 명시한다.

자리표 조작 → 예제 → 3개 풀이 원형의 연습 → 별도 평가 3문항 → 오답 피드백 → 다음 날 복습. D1 식별, D2 분해, D3 역추론을 제공한다. D4·D5는 계약만 지원하며 공개 문항은 없다. 평가 점수만으로 완료하지 않고 학습 블록 확인+세 개념 모두 숙달+평가 80% 이상을 함께 요구한다. 다음 M0-02는 초안이므로 링크를 활성화하지 않는다.
