# M2 배치 3 QA · M2-11~M2-15

## 범위

이차방정식의 풀이와 활용, 이차함수 그래프, 최대·최소, 닮음과 비례를 개발 전용 미리보기에 연결한다. 단원마다 6개 소단원·15단계·인터랙티브 활동, 연습 초안 6개와 문제 원형 2개가 있다. 신규 문항 30개이며 별도 평가는 추가하지 않는다.

모든 자료는 draft다. 작성자 정답 자체 확인 상태이며 사람 검수·승인·게시가 없다. 공식 성취기준 코드 매핑도 확인하지 않았다.

## 검증

- `npm run lint`: 통과
- `npm run typecheck`: 통과
- `npm test`: 13개 파일, 107개 테스트 통과. 첫 병렬 실행에서 기존 4자리 수 검사가 5초 제한을 넘었으나 단독 재실행은 통과.
- `npm run content:validate`: 3개 파일, 18개 테스트 통과
- `npm run build`: Next.js 프로덕션 빌드 통과
- `npm run test:e2e`: 테스트 auth service가 `127.0.0.1:54329`에 bind할 때 EPERM으로 시작 단계에서 차단, 브라우저 E2E 미검증.
- 개발 preview에만 노출하며 정본 curriculum, 평가·숙달 경계는 변경하지 않는다.
