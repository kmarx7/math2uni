# M5-12 문항 독립 검토

- 검토 대상: `problem-blueprint.json` v0.1.0-draft
- 결과: 6개 정답·좌표·정의역 확인; 게시 승인 아님
- 가족: 좌표 읽기 #01~02, 사분면/축 부호 #03~04, 탄젠트 비/정의 #05~06

## 재계산

| 문항 | 독립 계산한 답 | 검토 |
|---|---|---|
| m512-draft-01 | `cos(π/6)=√3/2` | 단위원 30° 좌표; 키 A 일치 |
| m512-draft-02 | `(cosθ,sinθ)=(−1/2,√3/2)` | 좌표 순서 유지; 키 C 일치 |
| m512-draft-03 | `sinθ<0, cosθ<0` | `5π/4=225°`, 제3사분면; 키 B 일치 |
| m512-draft-04 | `(cosθ,sinθ)=(0,−1)` | `3π/2`, 음의 y축; 키 A 일치 |
| m512-draft-05 | `tan(π/4)=1` | `cosθ=√2/2≠0`; 키 C 일치 |
| m512-draft-06 | `tan(π/2)`는 정의되지 않음 | `sin=1, cos=0`; 키 B 일치 |

가족은 좌표-함수 대응, 사분면/축 위치 판정, 분모 조건을 가진 탄젠트 비로 구분되며 기술 ID와 일치한다. 특히 축 끝점의 0 좌표와 `cosθ=0`에서 탄젠트 미정의를 검토했다. 모든 choice ID·라벨이 유일하고 정답 키와 해설이 일치한다. A/B/C 각 2회. 모든 문항은 practice draft, `humanVerified=false`, 자체 제작이며 assessment item은 없다.
