## 산출물

- M1-06~M1-10: 단원별 3문항 형성평가 초안 15개. 연습 초안과 `proposal-preview`로 분리했다. 답·해설은 GET 공개 DTO와 제출 전 화면에 없다.
- M1-11~M1-15: 각 6개 소단원·15단계 명세, 2개 문제 원형·6문항, 조작 실험실 5개.
- 신규 연습은 앞선 60개와 별도로 30개다. M1-01~M1-15 연습 초안 총 90개, 30개 사고 원형. M1-01~M1-10 평가 초안 총 30개.
- 학습 데이터는 계정별 `unitProgress[M1-xx]`에만 저장한다. `proposal-preview` 시도는 공식 숙달도·오답·복습에서 제외되며 M0 루트 진도와 점수는 보존한다.
- 공식 교육과정 출처를 확인해 별책 8 지정까지 확인했지만, 개별 M1 단원에 대한 성취기준 코드는 검증하지 않아 비워 뒀다. [공식 자료와 범위 한계](../../research/NEXT_BATCH/M1-11-15-research-report.md).

## 공개 및 안전 경계

- 개발 환경·preview 플래그·ID allowlist·로그인 조건을 모두 만족할 때만 M1 초안 preview를 제공한다.
- 답안 채점은 서버에서 제한된 객관식·정수 입력만 받는다. 임의 입력 수식 실행은 없다.
- preview 점수와 기록은 계정의 단원별 진도 칸에 저장하지만 정본 단원 완료/숙달도 판정은 아니다.
- 콘텐츠 승인은 `approvedContent: null`, humanApprovalCount 0으로 남긴다. 자동 계산 검증을 사람 승인으로 부르지 않는다.

## 남은 작업

1. 로컬 테스트 서비스가 포트를 열 수 있는 런타임에서 Playwright E2E를 다시 실행한다.
2. 30개 평가 초안과 새 연습 30개를 별도의 교육·수학 검수자가 검토한다.
3. M1-11~M1-15는 형성평가가 구현되지 않았다. 문항을 추가한 뒤 같은 전체 제출·비공개 경계를 검증한다.
4. 다음 묶음 M1-16~M1-20은 ID/선수 관계와 제안 교육과정 상태를 먼저 확인한 뒤 진행한다.
