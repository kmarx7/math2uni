# M4-20 구현 보고

- 상태: 미승인 draft 개발 미리보기. 공통 lesson renderer와 단원 전용 interactive lab에 연결했다.
- 단원: 공통수학2 연결 점검. 기존 근호·분모 조건의 교집합을 유한 표본 입력으로 확인하며 새로운 개념을 추가하지 않는다. 표본 결과가 전체 실수 정의역을 대신하지 않는다고 안내한다.
- 문제: server-only adapter로 자체 제작 연습 초안 6개/서로 다른 3개 원형을 연결했다. 평가 문항은 없다.
- 진도: preview 연습 시도는 `proposal-preview` 컬렉션의 M4-20 기록으로 격리한다. `m4-20-local-review-*` 기술 태그는 정식 교육과정 기술과 분리되어 숙달도에 반영되지 않는다.
- 보안: 공개 DTO에는 정답·해설·채점 규칙을 포함하지 않는다. 운영 환경에서 미승인 preview는 차단된다.
- 검수: 콘텐츠는 draft, 사람 검수/게시 승인 0건. 공식 성취기준 매핑은 미검증이다.
