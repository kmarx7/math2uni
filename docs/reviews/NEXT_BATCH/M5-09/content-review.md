# M5-09 문항 독립 검토

- 검토 대상: `problem-blueprint.json` v0.1.0-draft
- 결과: 현재 초안 6개 정답·키·풀이 확인; 게시 승인 아님
- 가족: 정의역/로그방정식 #01~02, 증가 밑 부등식 #03~04, 감소 밑 부등식 #05~06

## 재계산

| 문항 | 독립 계산한 답 | 검토 |
|---|---|---|
| m509-draft-01 | `x=9`; `x>1` | `x−1=2³=8`, 키 A가 9와 일치 |
| m509-draft-02 | `x=8`; `x>−1` | `x+1=3²=9`, 키 B가 8과 일치 |
| m509-draft-03 | `x>5` | 밑 2 증가, 진수 조건 `x>1`도 만족; 키 C 일치 |
| m509-draft-04 | `−1/2<x≤3` | 진수 조건과 증가성의 교집합; 키 A 일치 |
| m509-draft-05 | `0<x<4` | 밑 1/2 감소라 방향 반전, 진수 양수; 키 B 일치 |
| m509-draft-06 | `x≥3/2` | 밑 1/3 감소라 방향 반전, 진수 조건 `x>1/2`; 키 C 일치 |

세 가족의 추론 구조와 기술 ID가 대응한다. 각 문항은 선택지 3개이며 ID·라벨이 서로 다르고, 의미 답·정답 키·풀이가 일치한다. A/B/C 정답 위치는 각 2회다. 6문항 모두 `practice-draft`, `humanVerified=false`, 자체 제작 초안 권리 상태이며 평가 문항은 없다.

## 한계

정의역 밖 후보 제거, 로그 밑 조건 `a>0, a≠1`, 증가/감소 방향을 유지하도록 확인했다. 의미적 교육 적합성, 외부 독립 사람 검수, 공식 성취기준 매핑은 이 검토로 확정되지 않는다.
