# M1-01~M1-10 개발 미리보기 · 배치 2 QA

- 날짜: 2026-11-02
- 범위: M1-01~M1-05 형성평가 초안 추가, M1-06~M1-10 콘텐츠·연습 미리보기
- 상태: 개발·자동 검사 완료; 브라우저 E2E는 환경 오류로 미검증
- 정본 등록/사람 승인/게시: 해당 없음, 모두 미승인 초안

## 변경 내용

- M1-06~M1-10에 6개 소단원·15단계 학습 데이터와 단항식 곱, 동류항, 분배법칙 넓이, 등식 균형, 일차방정식 조작 도구를 연결했다.
- M1-01~M1-05 형성평가는 단원마다 3문항, 총 15문항이다. `proposal-preview` 컬렉션으로 연습·평가를 기존 `core`/`extended`와 분리했다. 제출 전에 공개되는 DTO에는 답·해설·풀이·채점 규칙이 없다. 전체 문항 ID와 답을 모두 제출해야 채점한다.
- M1-06~M1-10 연습 초안은 단원마다 6문항이며, M1-01~M1-05 연습 초안 30개와 합해 연습 초안 60개다. 기존 원형 10개와 새 원형 10개, 총 20개다. 숫자만 바꾼 문항은 원형으로 세지 않는다.
- 계정별 단원 기록은 `unitProgress[M1-xx]`에 저장한다. M0-01의 루트 점수와 블록 기록은 변경하지 않는다. `proposal-preview` Attempt는 공식 숙달도, 오답노트, 복습 일정에서 제외한다.
- M1-06~M1-10에는 아직 형성평가 문항이 없다. 화면에서 평가 준비 중인 단계로 유지한다.

브라우저 E2E 테스트 코드는 10개 단원의 화면, M1-01 전체 제출, 정답 비노출, 부분 제출 거부, M0 루트 점수 불변을 포함하도록 추가했다. 그러나 Playwright가 테스트용 서버를 띄우지 못해 이 흐름을 실제 브라우저에서 확인하지 못했다. 해당 항목을 통과로 기록하지 않는다.

## 운영·콘텐츠 경계

- 제안 ID와 교육과정 순서를 바꾸지 않았다. 신규 단원을 `curriculum` 또는 `canonicalManifest`에 등록하지 않았다.
- 미리보기는 로그인 및 개발 환경 변수와 정확한 ID allowlist를 요구한다. 운영 환경은 draft 미리보기와 문항을 제공하지 않는다.
- AI 생성 초안의 상태를 `draft`로 유지했다. 모든 단원 `approved-content.json`은 `approvedContent: null`, 승인 수 0이다.
- M1-01~M1-05 평가 답은 문항 데이터상 자체 재계산되었지만 사람 독립 검수는 아니다. 자동 검사는 게시 승인이 아니다.

## 남은 작업

1. Playwright 테스트 서비스를 허용된 로컬 런타임에서 실행하고 E2E를 재검증한다.
2. Curriculum/Research 검토자가 15개 평가 초안과 30개 신규 연습 초안을 독립 수학·교육 검수한다.
3. M1-06~M1-10의 별도 형성평가를 설계하기 전 해당 단원의 연습·개념 초안 검토를 마친다.
4. 다음 묶음 M1-11~M1-15 개발 전에 제안안 ID·선수 관계와 각 문항 원형을 확인한다.
