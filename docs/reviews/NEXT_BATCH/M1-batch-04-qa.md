# M1 배치 4 QA · M1-16~M1-20

## 작업 범위

- 개발 미리보기: M1-16 삼각형과 다각형, M1-17 평면도형의 넓이, M1-18 입체도형과 부피, M1-19 자료의 정리와 대표값, M1-20 수와 식 기초 종합.
- 단원당 6개 소단원, 15개 학습 단계, 인터랙티브 블록 1개, 연습 초안 6개/문제 원형 2개.
- 새 연습 문항 30개. M1-11~20에는 별도 평가 문제를 추가하지 않음.
- 문항·콘텐츠는 draft이며 사람 검수/승인/게시 모두 0건.

## 경계

- 기존 제안 단원 ID·순서·선수 관계를 변경하지 않음.
- 운영 curriculum/canonical list, official mastery, 복습/채점 경계에 합치지 않음.
- 개발 preview allowlist에서만 접근 가능. 운영 공개 승인 없음.
- 미검증 공식 성취기준 코드는 기입하지 않음. 연구 보고에 확인한 링크와 미확인 범위를 구분했다.
