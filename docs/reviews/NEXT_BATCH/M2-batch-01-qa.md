# M2 배치 1 QA · M2-01~M2-05

## 범위

연립일차방정식의 뜻·풀이·활용과 일차함수의 의미·그래프를 개발 전용 미리보기로 추가했다. 단원당 6개 소단원, 15단계, 인터랙티브 활동, 연습 문항 6개/문제 원형 2개다. 새 연습 초안은 30개이며 형성평가 문항은 추가하지 않았다.

## 검증 상태

- `npm run lint`: 통과
- `npm run typecheck`: 통과
- `npm test`: 13개 파일, 107개 테스트 통과
- `npm run content:validate`: 3개 파일, 18개 테스트 통과
- `npm run build`: Next.js 프로덕션 빌드 통과
- 브라우저 E2E: 테스트 auth 서비스가 `127.0.0.1:54329`에 bind할 때 `EPERM`으로 시작하지 못함. 브라우저 흐름은 미검증.
- 공식 교육과정 성취기준 코드 매핑: 미검증.
- 독립 교육·수학 검수 / 승인 / 게시: 0건.

## 경계

제안 ID·순서·선수 관계를 유지한다. M2 단원은 proposal preview manifest만 이용하며 정본 curriculum/채점/숙달에 포함하지 않는다. 콘텐츠/문항은 draft이고 승인 대기 데이터는 null이다.
