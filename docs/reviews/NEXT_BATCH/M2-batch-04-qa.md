# M2-16~M2-20 통합 QA 보고

- 범위: 개발 preview manifest, 공통 수업 렌더러, 유형별 인터랙티브 도구, 연습 문제 DTO, `unitProgress[unitId]` 경계.
- 교육 콘텐츠: 단원별 15단계, 개념 설명 6개 섹션, 연습 초안 6문항/2개 원형. 평가 문항 없음.
- 상태: 모든 콘텐츠는 draft이며 `approvedContent: null`; 사람의 독립 검수와 공개 승인은 없다. 공식 성취기준 매핑 미검증.
- 검증 결과는 실행 후 이 문서와 단원별 qa-report.md에 기록한다. 검증에 실패하거나 실행하지 못한 항목은 통과로 표시하지 않는다.

## 독립 초안 검토 반영

- 교육과정 역할 검토가 최초 문구의 반복과 WorkedExample의 비구체성을 지적했다. 다섯 단원의 설명 섹션, 선수학습 진단, 예제 풀이를 단원별 개념·수치로 보강했다.
- 문제 역할 검토가 정답 대조상 계산 오류는 찾지 못했으나, 일부 원형의 사고 구조 분리가 약하다고 지적했다. 원형 제목·전략을 구체화하고 M2-16의 판별/계산, M2-19의 분산/상관, M2-20의 표현 분류/복합 풀이를 구분했다. 사람의 독립 검수는 여전히 필요하다.
- M2-19에는 상관 거의 없음 문항과 양·음·약한/거의 없음 산점도 활동 예시를 추가했다. M2-20에는 직사각형 대각선과 넓이를 각각 구하는 두 개념 결합 문항을 넣었다.
- M2-16의 prerequisite units 목록은 기존 제안 값(M2-07, M1-17)을 유지했다. 삼각형 변 이름을 다룬 M1-16을 추가 선수로 둘지 검토 제안만 기록했다.
