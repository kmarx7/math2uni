신규 E2E는 `tests/e2e/m001-expansion.spec.ts`의 4개 사례(데스크톱/모바일 각 2개)이다. 실제 Auth/DB 자체를 대신 검증하지 않으며 격리된 테스트 fixture를 사용하는 기존 전체 모음에 포함한다. 이 파일은 자동 실행 전 결과를 통과로 예고하지 않는다.

발견·해결한 문제:

1. 신규 평가 문항을 기본 3평가에 합치면 기존 제출 집합이 바뀌는 문제를 `collection` 분리로 해결했다.
2. 확장 평가 점수만 저장하지 않아도 확장 오답이 기존 숙달을 떨어뜨릴 수 있었다. Orchestrator가 시도에 collection을 추가하고 핵심 숙달에서 확장 증거를 분리했다. 이 회귀를 Developer 집중 검사에 추가해 통과했다.
3. 보기의 수치가 바뀌고 검증 메타데이터만 원래대로 남으면 자기 채점은 통과할 수 있다. 실제 보기 본문과 계산 입력을 대조하는 제한 검사를 추가했다.
4. Research와 교차 검토하여 자리 변경 3문항을 변경 후 수가 아닌 증가·감소량 700/70/5000으로 명세·질문·정답·해설을 일치시켰다. 거짓 주장을 인용하는 오류 발견 문항은 거짓임을 해설에서 명시한다.

학습 효과, 수능 90점 달성, 실물 모바일/스크린리더 사용자 평가, 공식 성취기준 전수 대조는 미검증이다. D4~D5 문항과 추가 제약을 갖춘 생성 템플릿은 후속 개발이다.

## Orchestrator 최종 통합 실행

- lint, typecheck, 전체 단위/계약 101개, production 빌드 통과.
- agents:validate: staged TOML 구문/역할 필드 통과. `.codex` 설치/런타임 역할 발견은 보호 경로 쓰기 거부로 미검증이다.
- content:validate: 14개 통과. 102개 전체 고정 문항·40개 고유 원형의 중복/참조와 30개 신규 정답·공개 경계·버전/해시·독립 설계 인계를 확인한다.
- 최종 `npm run test:smoke`: **52/52 통과, 2.3m, exit 0**, 한 Chromium 작업자의 데스크톱/모바일 컨텍스트로 전체 실행 완료.
- `npm run test:e2e`: sandbox의 fixture 포트 listen EPERM으로 실행 차단. 동일한 Playwright 모음의 위 별칭 결과와 구분한다.
- `npm run curriculum:canonical`: 정본 미등록/12개 등록으로 실패. 170개 완성으로 보고하지 않는다.

중간 실패와 해결: 생성 중인 `.next-e2e` validator를 일반 타입 검사에서 읽은 충돌을 E2E 산출물 제외/순차 검증으로 해결했다. cold RSC 전환은 실제 URL commit을 기다리도록 검사했고 단독 2개 재실행도 통과했다. 두 작업자의 테스트 계정 준비에서 일시 ECONNRESET이 발생한 후, 준비 요청의 해당 네트워크 오류 재시도와 한 작업자 실행을 적용하고 전체 52개를 재실행해 통과했다. HTTP 실패 상태나 기능 assertion을 재시도로 숨기지 않는다.

신규 6개 소단원 설명/3개 조작 활동은 교육 역할의 수학·문구 교차 검토를 받았다. production에서 미승인 확장 문서/활동을 표시하지 않는 서버 전달 게이트와 본문 없는 클라이언트 완료 인덱스도 추가 검사했다. 모바일/데스크톱 새 조작 화면 캡처를 직접 확인했다. 문항은 여전히 draft이고 사람 승인은 0개다.
