# M3-11~M3-15 독립 교육과정·콘텐츠 검토

- 검토일: 2026-11-03
- 검토자: Curriculum Architect 독립 검토자 (명세/문항 작성자와 별도 agent)
- 작성 역할: Curriculum Architect가 `lesson-spec.json`을 작성했고 Research & Content가 수업 초안·문제 청사진을 작성했다.
- 검토 입력: 다섯 단원 명세, 학습 초안, 연구·출처 기록, 문제 청사진, 앞선 작성자 검토 이력, 제안 메타데이터.

## 판정

Curriculum 설계는 **Developer 인계 준비 완료(implementation-ready)**로 판단한다. 명세와 학습 초안의 인터랙션 ID가 모두 맞고, 선수 진단이 제안 메타데이터에 기재된 선수 단원의 내용과 일치한다. 예제와 30개 문항의 독립 계산에서 수학 오류를 찾지 못했다.

다섯 새 인터랙션 ID는 현재 Zod `contentSchema` enum에 아직 등록되지 않았다. 이는 콘텐츠 설계 차단 항목은 아니며, Developer가 enum·렌더러·테스트를 추가한 뒤 전체 lesson JSON을 실제 스키마로 파싱해야 하는 구현 선행 작업이다.

이 판정은 개발 인계용 Curriculum 검토다. 사람의 콘텐츠 승인, 문항 게시 승인, 운영 공개 승인을 뜻하지 않는다. 콘텐츠와 문항은 draft이며 공식 성취기준 매핑은 미검증이다.

## 선수 진단과 교육 흐름

| 단원 | 명세의 선수 진단 | 검토 |
|---|---|---|
| M3-11 | M3-10 표준형 계수 읽기, M3-02 이차식 전개와 계수 비교 | 실제 제안 개념과 부합. 근·계수 공식 자체를 미리 알도록 요구하지 않는다. |
| M3-12 | M3-10 판별식으로 실근 분류, M2-13 그래프·꼭짓점 읽기 | 실제 선수 기능에 부합한다. x축 및 y=k와의 교점을 방정식·그래프 양쪽으로 연결한다. |
| M3-13 | M3-12 그래프·꼭짓점·대칭축, M2-14 닫힌 구간·끝점 해석 | 닫힌 구간이라는 조건을 정확히 사용하고, 구간 안의 꼭짓점과 양 끝점을 비교한다. |
| M3-14 | M3-07 인수분해·묶기, M3-10 인수분해와 영곱 성질 | 제안 선수 기능과 맞다. `t=x²`에서 `t≥0`, 양수 t의 역치환 `x=±√t`를 설명하고 일반 삼차·사차 공식이 있다고 오해시키지 않는다. |
| M3-15 | M3-14 인수에서 근 찾기·검산, M2-02 대입법 및 순서쌍 | 수정 후 선수 단원과 진단 설명이 일치한다. 대칭형의 합·곱 방법을 사전 능력으로 요구하지 않고 M3-15 안에서 먼저 설명한다. |

다섯 명세 모두 6개 소단원, 15단계, 목표 기술 2개와 6개 개념 학습 섹션을 갖는다. 용어 정의와 풀이 절차가 이를 사용하는 문제보다 먼저 제시되어 있다. 그래프/조작 활동은 텍스트 결과 설명과 키보드 제어를 명세한다. 실제 접근성 동작은 Developer 검증 대상이다.

## 독립 수학 검산

다섯 명세의 WorkedExample와 청사진의 모든 정답 30개를 다시 계산했다.

| 단원 | 문항 정답 순서 (p01~p06) | 예제 검산 |
|---|---|---|
| M3-11 | `7/2`, `−3`, `13`, `9`, `−12`, `8` | 근 2,3: 합 5, 곱 6, 제곱합 13 |
| M3-12 | `2`, `5`, `2`, `1`, `−3`, `4` | 교점 (1,0),(3,0), 판별식 4 |
| M3-13 | `1`, `4`, `4`, `−4`, `9`, `16` | 명세 예제의 닫힌 구간에서 최댓값 4, 최솟값 0 |
| M3-14 | `3`, `3`, `4`, `0`, `2`, `2` | `t=x²`에서 t=1,4, 실근 −2,−1,1,2 |
| M3-15 | `1`, `2`, `3`, `1`, `12`, `3` | 교점 (2,3),(−1,0) |

각 단원은 3개의 서로 다른 추론 구조를 가진 원형과 원형당 2문항으로 구성한다. 숫자만 달라진 문항은 별도 원형으로 세지 않았다. 30개 기술 ID는 명세의 `targetSkills`에 포함되고 모든 문항은 draft다.

## 상호작용·출처·상태

명세와 lesson draft의 상호작용 ID 일치를 확인했다.

- M3-11 `root-coefficient`
- M3-12 `quadratic-intersection`
- M3-13 `quadratic-interval-optimization`
- M3-14 `polynomial-root-factory`
- M3-15 `system-intersections`

각 ID는 현재 Zod enum에 없으므로 Developer가 등록해야 실제 `contentSchema` 파싱이 완료된다. Research는 이 제한을 분명히 표시했다.

교육부 2022 개정 교육과정 발표 페이지는 직접 확인된 맥락 자료이며 단원별 매핑을 뒷받침하지 않는다. NCIC는 공식 사이트 검색 결과를 찾았지만 직접 URL 요청은 404였다고 기록되어 있으므로 페이지 직접 검증으로 취급하지 않는다. 명세의 `officialStandards`는 빈 배열이고 별도 공식 코드가 임의로 추가되지 않았다. 교육부/NCIC 자료의 권리 조건을 구별해 기록했으며 외부 기출·교재 문항을 복제하지 않았다. 교수법·오개념 진술은 독립 연구로 확인된 사실이 아니라 작성자 가설이다.

다섯 학습 초안은 `draft`, `publicationApproved=false`, `humanVerified=false`다. 평가 문항/AssessmentBlock은 없고 `approved-content.json`은 승인 내용을 `null`로 둔다. 공개·게시 승인은 없다.

## 비차단 문서 일관성 메모

M3-11과 M3-13의 명세 예제와 lesson draft의 WorkedExample는 서로 다른 수식을 사용한다. M3-11은 같은 근 2,3을 갖는 식의 상수배 버전이며 같은 기술을 연습한다. M3-13은 다른 닫힌 구간과 포물선 방향을 사용하지만 꼭짓점·끝점 비교라는 목표에 부합한다. 런타임 lesson draft의 예제를 구현 기준으로 삼으면 교육적 충돌은 없다. 앞선 작성자 검토 보고서의 M3-13 예제 요약은 이전 예제 문구가 남아 현재 명세와 일치하지 않으므로 문서 정리 때 갱신할 필요가 있다.
