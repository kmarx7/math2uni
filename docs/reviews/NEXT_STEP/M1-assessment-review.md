# M1-01~M1-05 형성평가 범위 검토

- 검토 역할: Curriculum Architect 교육 설계 검토
- 대상 버전: 각 단원 lesson-spec v0.1.0-draft
- 판정: 평가 설계 보완 제안. 콘텐츠 승인이나 게시 승인 아님
- 공식 성취기준: 확인된 코드 연결 없음

## 종합 의견

다섯 단원 모두 핵심 개념, 계산, 설명 또는 오류 분석을 평가 항목에 포함해 큰 틀의 목표와 연결되어 있다. 다만 현재 항목은 평가 영역 수준의 목록이다. 실제 문항 청사진이 작성될 때 각 목표 기술에 최소 한 개 이상의 독립 사고 원형을 연결하고, 연습에서 본 숫자만 바꾼 문항을 평가 증거로 중복 계산하지 않는 매핑이 필요하다. 수치 숙달 기준은 파일럿 전 확정하지 않는 현재 방침을 유지한다.

## 문항 설계·채점 권고

1. 목표 기술 → 문제 원형 → 평가 문항 간 추적표를 만든다. 각 목표에 계산·설명·표현 변환 가운데 적절한 두 가지 유형을 조합한다.
2. 형성평가는 전체 응답 제출 후 결과를 공개한다. 힌트를 사용한 시도와 첫 독립 응답을 별도 기록해 숙달 증거가 혼합되지 않게 한다.
3. 정답 일치만으로 설명 문항을 숙달 처리하지 않는다. 설명형은 승인된 핵심 근거 요소를 명시하고, 자동 채점이 불확실하면 수동 검토 대상으로 둔다.
4. 연습 문항과 평가 문항은 별도 collection 및 원형으로 관리한다. 숫자 치환만 한 변형을 새로운 사고 유형이나 독립 증거로 세지 않는다.
5. 단원 완료 점수의 기준값은 표본 응답과 문항 분석 전에는 고정하지 않는다. 점수는 해당 평가의 수행 결과이며 수능 점수 예측이나 보장이 아니다.
6. 정답·해설은 평가 전체 제출 전 클라이언트에 노출하지 않는다. 미승인 문제는 개발 검토 외 공개 경로를 차단한다.

## 검토 범위와 미완료

이번 검토는 lesson-spec의 목표와 평가 항목 간 내용 범위를 살핀 설계 검토다. 실제 문항 난도, 정답·해설 정합성, 문항 간 중복, 채점 규칙, 학습 효과는 검증하지 않았다. 각 단원의 문제 청사진·초안이 작성된 뒤 독립적인 수학 검사 및 QA를 수행해야 한다. 이 기록은 사람의 게시 승인을 대신하지 않는다.
