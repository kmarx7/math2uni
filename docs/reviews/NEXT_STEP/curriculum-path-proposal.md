# 새 마스터 경로 배치 초안 · 검토 대기

- 작성 역할: Curriculum Architect
- 상태: 제안(draft), 2차 교육 검토 완료 · 사용자·공식 교육과정 검수 대기
- 목적: 기존 제안 `unitId`와 역사적 `level/order`를 보존하면서 최신 수량을 교육적으로 배치할 수 있는 `pathLevel/pathOrder` 후보를 제시한다.
- 정본 여부: 아님. `src/data/curriculum-proposal.ts`, 등록 교육과정, 진도 데이터에 반영하지 않는다.

## 원칙과 검증 범위

단원 ID, 기존 LEVEL, 기존 순서는 재명명하거나 덮어쓰지 않는다. 여기의 `pathLevel/pathOrder`는 학습 경로상 배치 후보이며 기존 `Unit.level/order`를 대체하지 않는다. 각 제안 ID는 한 경로 슬롯에 정확히 한 번 배치했다.

사용자 목표 수량은 **설계 기준**으로 확인했다. 기존 M0-01~M0-12는 그대로 두고, 기존 제안 목록의 M1~M8 ID를 새 경로에 재배치한다. 1차 안은 요청 숫자에 맞는 1:1 배치와 선수 순서를 만족했지만, LEVEL 7의 통계 추정을 LEVEL 8에서 처음 가르치고 LEVEL 1·2 주제명이 실제 내용과 어긋나 교육적으로는 비권고다. 2차 권고는 추정 단원을 LEVEL 7에 보존하고 **LEVEL 7을 20, LEVEL 8을 18로 조정**한다. 합계는 170을 유지한다.

## 경로 슬롯 후보

각 셀은 왼쪽부터 `pathOrder` 순서다. 범위 표기는 양끝 ID를 포함한다.

| 새 경로 LEVEL / 기준 주제 | pathOrder에 배치할 기존 unitId | 수 |
| --- | --- | ---: |
| 0 · 수와 연산 기초 | M0-01~M0-12 | 12 |
| 1 · 수·문자식·초기 방정식 *(제목 조정 제안)* | M1-01~M1-12 → M2-01~M2-02 | 14 |
| 2 · 중학 대수와 공통수학 대수 진입 *(제목 조정 제안)* | M2-03 → M2-07~M2-12 → M3-01~M3-11 | 18 |
| 3 · 중학 함수·기하·확률 | M1-13~M1-20 → M2-04~M2-06 → M2-13~M2-20 → M3-19~M3-20 → M4-09 | 22 |
| 4 · 고교 공통수학 | M3-12, M3-14~M3-17, M3-21 → M4-01~M4-08 → M4-10~M4-19 | 24 |
| 5 · 대수 | M5-01~M5-09 → M5-11~M5-17 → M5-19~M5-22 | 20 |
| 6 · 미적분Ⅰ | M6-01~M6-15 → M6-17~M6-23 | 22 |
| 7 · 확률과 통계 *(수량 조정 제안)* | M7-01~M7-20 | 20 |
| 8 · 수능 실전 *(수량 조정 제안)* | M3-13, M3-18, M3-22 → M4-20 → M5-10, M5-18, M5-23, M5-24 → M6-16, M6-24 → M8-01~M8-08 | 18 |

**2차 수량:** 12 / 14 / 18 / 22 / 24 / 20 / 22 / **20 / 18** = 170. 1차와 비교해 M7-19·M7-20을 LEVEL 8에서 LEVEL 7로 되돌리고, 기존 공통수학 연결/응용 단원 M3-13·M3-18·M3-22를 LEVEL 8로 옮겼다. M4-13·M4-14·M4-19는 공통수학 개념 학습에 남겼다. 1차의 18/20 수량은 그대로 구현하지 않는 것을 권고한다.

## 배치 이유와 경계 위험

- **LEVEL 1:** M1-01~12에는 수 체계의 기초와 문자·식이 함께 있고, M2-01~02는 연립일차방정식의 뜻과 풀이이다. 단원 주제는 사용자가 요청한 좁은 제목 “문자와 식”만으로 설명되지 않는다. 기존 단원 범위와 수량을 유지하는 최소 수정은 제목을 **“수·문자식·초기 방정식”**처럼 넓히는 것이다. 제목을 절대 유지해야 한다면 M1 기초 단원을 LEVEL 0에 통합하고 ID별 합치기/하위 블록 대응을 설계해야 하므로 단순 1:1 재배치가 아니다.
- **LEVEL 2:** M2-03 및 M2-07~12에는 중학 연립/근호/이차방정식이 있고 M3-01~11에는 다항식 구조·나머지/인수정리·복소수·이차방정식이 있다. Research 조사에서 공통수학1의 다항식·방정식 계열은 별도 고교 범위 후보로 분류됐다. 그러므로 “중학 대수”라는 제목만 넓혀도 M3-01~11의 단계가 중학 내용으로 바뀌지는 않는다. 이 배치를 쓸 경우 제목은 적어도 **“중학 대수와 공통수학 대수 진입”**으로 바꾸고 수준 전이를 명시해야 한다. 원래 요청의 제목/학교급 경계를 엄격히 지키려면 M2/M3 개념을 다른 LEVEL로 옮기는 분할·합치기와 슬롯 재계산이 필요하다. 제목 변경만으로 공식 범위 대응이 승인되는 것은 아니다.
- **LEVEL 3:** 좌표·비례, 기하, 자료·산포도, 함수, 경우의 수를 중심으로 둔다. M4-09 집합 표현을 확률의 선수 연결로 포함한다. M3-19~20의 경우의 수·순열/조합은 중학 확률 기초와 고교 조합의 경계를 추가 검수해야 한다.
- **LEVEL 4:** 좌표기하, 집합·논리, 함수와 함께 이차방정식·부등식·행렬 등 공통수학 연결을 배치한다. M4-09와 M4-15~16은 선수 개념을 고려해 앞 LEVEL에 배치했다.
- **LEVEL 5:** 지수·로그, 삼각함수, 수열의 핵심 단원을 남긴다. M5-10 지수·로그 활용, M5-18 삼각형 응용, M5-23 귀납법, M5-24 통합 점검은 LEVEL 8로 옮겨 기본 개념 뒤의 전이·증명·통합 활동으로 배치한다.
- **LEVEL 6:** 미분·적분의 핵심 개념을 두고 방정식·부등식 응용(M6-16)과 종합 점검(M6-24)은 선수 단원 완료 뒤 LEVEL 8에서 통합한다.
- **LEVEL 7:** M7-01~20을 둬서 모평균 추정(M7-19)과 모비율 추정(M7-20)의 **최초 교수**를 확률과 통계 단계에서 완료한다. 조사 자료는 통계가 고교 확률과 통계 범위의 한 영역이며 모비율 추정 주제도 검토 대상임을 지지한다. 현재 공식 원문 대조는 부분 조사이므로 세부 코드 매핑은 보류한다.
- **LEVEL 8:** 처음 배우는 P&S 추정 단원이 아니라 앞서 학습한 개념의 전이·통합·독립 평가로 한정한다. 2차 안의 M3-13(함수 최적화 응용), M3-18/M3-22/M4-20(과정 간 통합), M5-10/M5-18/M6-16(과목 개념을 이용한 응용), M5-24/M6-24(종합 점검), M8-01~08(조건 해석·통합 전략·독립 수행/평가)을 전이/평가 단위로 분류한다. M5-23 수학적 귀납법은 단순 전이 문항 묶음이 아니라 별도 증명 전략의 학습 목표다. 공식 수능 범위 여부를 확인하기 전에는 “수능 필수”로 표시하지 않으며, LEVEL 8에서 새 전략을 처음 지도하는 선택 학습으로 구분한다.
- **LEVEL 8에서 제외:** 1차 안의 M4-13(명제 증명), M4-14(절대부등식), M4-19(무리함수)는 공통수학 개념 본체다. 단지 선수 ID가 먼저 있다는 이유로 이 ID들을 Level 8에 옮기면 해당 개념을 그곳에서 처음 가르치게 된다. 따라서 2차 안에서 LEVEL 4로 돌렸다. M7-19/20도 같은 이유로 최초 교수 LEVEL 8 배치를 철회했다.
- **전이 단위와 신규 단위:** 2차 안의 LEVEL 8에는 새 `unitId`를 만들지 않는다. M8-01~08은 서로 구분되는 기존 통합·실전 전략 학습 단위다. M3/M4/M5/M6에서 옮긴 나머지 10개는 기존 응용/점검 ID를 전이 수준으로 재배치한 것이다. 이를 무작위 숫자 변형이나 새 문제 원형 수로 세지 않는다. 별개의 신규 실전 단원 12개를 추가하겠다면 170 총수를 유지하기 위한 명시적 병합/대응표가 먼저 필요하므로 이번 2차 안에는 넣지 않았다.

## 선수 그래프 확인

2차 `(pathLevel, pathOrder)` 후보는 검사 시 수량 `[12,14,18,22,24,20,22,20,18]`, 전체 170개 ID의 유일·완전 배치, 정의된 선수 선행 순서를 모두 만족했다. 예를 들어 M2-01~02는 M1-10 뒤, M2-13~14는 M2-05 뒤, M3-05~07은 M3-03~06 뒤, M4-19는 M4-17 뒤, M4-20은 M4-14/18/19 뒤, M7-19/20은 M7-18 및 각 선수 분포 뒤, M8-01은 M5/M6 전이 단원 뒤에 배치된다. 이 검사는 데이터 내 선수 ID 순서만 검증하며 공식 교육과정 적합성을 증명하지 않는다.

이 검사는 파일에 기록된 단원 단위 선수 연결만 사용한다. 선수 개념 단위의 최소 숙달 요건, 미기록 선수 관계, 공식 교육과정의 선수 범위는 확인하지 않았다.

## 미확인 사항과 다음 검토

공식 교육과정 코드나 170개 공식 단원 목록은 확인·생성하지 않았다. 기존 제안의 주제 배치도 공식 성취기준과 대조 완료 상태가 아니다. 최신 목표가 공식 170개 편성인지 Math 90 자체 학습 경로인지도 이 파일만으로 승인하지 않는다.

1. 사용자 결정: LEVEL 1·2 제목을 확장한 2차 제안을 채택할지, 원래 제목을 지키도록 ID 보존 split/merge 대응표를 먼저 만들지 결정한다.
2. 사용자 결정: 새 수량으로 조정한 LEVEL 7=20/LEVEL 8=18을 채택할지 결정한다. 추정 단원은 LEVEL 7에서 처음 가르치는 안을 권고한다.
3. Research 공식 원문 재대조와 Curriculum 독립 교차검토 전에는 모든 단원 매핑을 `proposed`로 둔다. 세부 성취기준은 현 상태로 확정하지 않는다.
4. 실제 path 제안 계약에는 기존 `unitId`와 별도 `pathLevel/pathOrder`, 주제 역할(`core_instruction`, `transfer`, `assessment`), 최초 교수 경로를 두어야 한다. 구현 감사가 권고한 대로 기존 `Unit.level/order`를 덮어쓰지 않는다.
5. 정본 manifest·앱 경로·콘텐츠 게시에는 사용하지 않는다. 교육과정 경계가 해결된 뒤에도 별도 사용자 검토와 공식 코드 원문 확인이 필요하다.

이 초안의 경로 배치가 미검증 공식 범위를 서비스로 확정하거나, 170개 콘텐츠가 완성되었다는 뜻은 아니다.
