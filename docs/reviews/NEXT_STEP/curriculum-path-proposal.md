# Math 90 마스터 학습 경로 결정안

- 작성 역할: Curriculum Architect
- 버전: 0.3.0-proposed
- 상태: **Math 90 설계 배분 결정 완료 · 제안 경로 · 공식 교육과정/운영 정본 아님**
- 결정 근거: 사용자의 최신 LEVEL별 목표 수량과 기존 단원 ID 보존 지시
- 승인 경계: 제안 경로 배분을 개발 기준으로 고정한다. 교육부 성취기준 매핑, 단원 교육 적합성에 대한 사람의 검수, 운영 공개는 승인된 것이 아니다.

## 결정 요약

최신 사용자 기준인 `12 / 14 / 18 / 22 / 24 / 20 / 22 / 18 / 20`을 Math 90 제안 경로의 고정 목표로 채택한다. 총합은 170이다. 기존 M0~M8 식별자·단원명·역사적 `level/order`는 바꾸지 않으며, 새 소속은 별도의 `learningPath.pathLevel/pathOrder`로 관리한다.

| 경로 LEVEL | 확정할 표시명 | 수량 | 주된 역할 |
|---:|---|---:|---|
| 0 | 수와 연산 기초 | 12 | 기초 개념 |
| 1 | 수·문자와 식·초기 방정식 | 14 | 수 체계에서 문자식과 초기 방정식으로 연결 |
| 2 | 중학 대수·공통수학 대수 진입 | 18 | 중학 대수에서 고교 다항식·방정식으로 연결 |
| 3 | 중학 함수·기하·확률 | 22 | 중학 함수, 기하, 자료와 경우의 수 기초 |
| 4 | 고교 공통수학 | 24 | 공통수학 개념 학습 |
| 5 | 대수 | 20 | 대수 개념 학습 |
| 6 | 미적분Ⅰ | 22 | 미적분Ⅰ 개념 학습 |
| 7 | 확률과 통계 | 18 | 확률·통계 개념 학습과 추정의 선수 개념 |
| 8 | 수능 실전 | 20 | 확률 추정 보완 후 응용·전이·통합·독립 평가 |

LEVEL 1·2 표시명은 이 경로에 실제 배치된 기초 수 및 고교 대수 진입 내용을 숨기지 않도록 넓혔다. 이 변경은 단원 자체의 `title`을 수정하지 않는다.

## 단원 ID 배치

각 묶음의 나열 순서가 해당 경로의 학습 순서다. 범위 표기의 양 끝 ID를 포함한다.

| LEVEL | 배치된 기존 `unitId` | 수 |
|---:|---|---:|
| 0 | M0-01~M0-12 | 12 |
| 1 | M1-01~M1-12 → M2-01~M2-02 | 14 |
| 2 | M2-03 → M2-07~M2-12 → M3-01~M3-11 | 18 |
| 3 | M1-13~M1-20 → M2-04~M2-06 → M2-13~M2-20 → M3-19~M3-20 → M4-09 | 22 |
| 4 | M3-12 → M3-14~M3-17 → M3-21 → M4-01~M4-08 → M4-10~M4-19 | 24 |
| 5 | M5-01~M5-09 → M5-11~M5-17 → M5-19~M5-22 | 20 |
| 6 | M6-01~M6-15 → M6-17~M6-23 | 22 |
| 7 | M7-01~M7-18 | 18 |
| 8 | M7-19~M7-20 → M3-13 → M3-18 → M3-22 → M4-20 → M5-10 → M5-18 → M5-23~M5-24 → M6-16 → M6-24 → M8-01~M8-08 | 20 |

M7-19 (모평균 추정)과 M7-20 (모비율 추정)은 사용자가 요청한 LEVEL 7 수량 18을 지키기 위해 LEVEL 8 맨 앞의 **첫 교수 후보**로 둔다. 이 두 단원은 전이 연습으로 가장하지 않는다. 표본·표집분포 등 필요한 선수 개념은 LEVEL 7에서 확보하고, LEVEL 8에서 추정의 뜻과 절차를 명시적으로 가르친 다음 통합·전이 활동으로 연결한다. 이 배치는 Math 90 내부 제안이며, 두 추정 주제가 2028학년도 이후 수능의 직접 출제 범위라는 주장이 아니다.

LEVEL 8은 2개의 통계 추정 첫 교수 후보와 응용·전이·점검·실전 전략 단원으로 이뤄진다. “수능 실전” 표시는 학습 경로의 기능을 나타내며 각 편성이 공식 출제 범위라고 보증하지 않는다. M5-23 귀납법과 M3-18 등 범위가 추가 확인을 필요로 하는 단원은 계속 확장/범위 미검증으로 표시한다.

## 교육 설계와 기존 ID 보존

- LEVEL 1의 M1-01~04는 정수·유리수·거듭제곱 등 문자식에 필요한 수 기초를 포함한다. M2-01~02는 방정식의 의미와 풀이에 연결된다. 따라서 LEVEL 제목을 “문자와 식”만으로 좁히지 않는다.
- LEVEL 2의 M3-01~11은 다항식, 복소수, 이차방정식 등 고교 대수 진입 내용을 포함한다. 이 내용을 중학교 수학으로 재분류하지 않고 제목에 전이를 드러낸다.
- M3-19~20은 경우의 수 기초를 LEVEL 3에 배치하고, M7-19~20은 선수 개념 이후의 통계 추정 첫 교수 후보로 LEVEL 8에 둔다. 두 범위가 공식 과목에서 차지하는 위치는 교육과정 원문 대조 후 별도 검증한다.
- M3-13, M3-18, M3-22, M4-20, M5-10, M5-18, M5-23~24, M6-16, M6-24는 선행 개념을 사용한 응용·연결·점검 후보로 LEVEL 8에 둔다.
- 단원 `unitId`, `title`, 역사적 `level/order`, 문항 ID, 계정 진도는 변경하지 않는다. 제안 경로가 정본으로 승인되기 전에는 기존 `Unit.level/order`나 canonical manifest를 수정하지 않는다.
- 선행 그래프 검사는 현재 저장된 단원 단위 관계만 검사한다. 누락된 개념 선수관계와 실제 숙달 문턱은 콘텐츠를 작성하며 구체화한다.

## 확정 상태와 남은 게이트

이 문서에서 내부 설계 결정이 확정된 것은 다음 두 가지다.

1. 최신 사용자 목표 수량 170개를 제안 경로의 배분 기준으로 사용한다.
2. LEVEL 1·2의 표시명을 실제 배치에 맞게 넓히고, M7-19~20을 LEVEL 8 첫 교수 후보로 명시한다.

다음은 확정되지 않았다.

- 원본 공식 170단원 목록과 공식 성취기준 코드는 확보·대조되지 않았다. `officialStandards`는 검증 전까지 비워 둔다.
- 사람이 단원별 교육 내용·문항·권리·평가를 검수하고 공개를 승인하지 않았다.
- 기존 M1~M8 제안의 제목·개념·선수관계가 공식 교육과정과 완전히 일치하는지 검증하지 않았다.
- 정본 등록, 운영 경로 활성화, 실제 사용자 진도 이관은 승인·실행하지 않는다.

따라서 경로 상태는 계속 `proposed`이며, 개발 프리뷰와 설계 검토에만 사용한다. 콘텐츠 승인과 운영 공개는 별도의 사람 검수·관리자 승인 절차를 거친다.
