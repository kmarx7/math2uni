## 확인 결과

- 다섯 명세는 각 6개 소단원과 15단계 학습 흐름을 포함한다. 제안 ID, 단원 순서와 선수 관계는 유지되어 있다.
- 각 수업 초안에는 6개의 설명·활동 소단원, 단계 예제, 오답 피드백과 복습 골격이 있다. 시각 활동은 키보드 조작·텍스트 대체·동작 감소 요구사항을 기록한다.
- 문제 청사진은 단원별 3개 추론 원형과 원형별 2개, 총 15개 원형·30개 연습 초안이다. 평가 문항은 포함하지 않았다. 모든 문항과 콘텐츠가 draft이며 `humanVerified=false`, `publicationApproved=false`다.
- 출처는 교육부의 2022 개정 교육과정 발표 맥락을 확인하는 데만 사용되며, 세부 성취기준 코드나 단원 매핑을 주장하지 않는다. 자체 제작 문항으로 표시하고 제3자 문항 복제를 주장하지 않는다.
- 예제 계산을 독립적으로 재검산했다. M3-06의 `(x−2)(x−1)(x+1)`, M3-07의 `(x−1)(x+1)(x−2)(x+2)`, M3-08의 `Re(−4−3i)=−4`, `Im(−4−3i)=−3`, M3-09의 `(3+2i)/(1−i)=1/2+(5/2)i`, M3-10의 `D=−36`, 근 `2±3i`는 맞다. 문제 초안의 산술·대수 결과도 대조한 범위에서 맞다.
- 문제 원형은 계산 결과만 바꾼 분리가 아니다. 대입 판정/부호 대응/계수 결정, 치환/묶기/전략 선택, 제곱근 표현/성분 판독/동일성, 성분 연산/분배 곱셈/켤레 나눗셈, D 계산/D 분류/복소근 구하기로 서로 다른 추론을 요구한다.

## 구현 인계 차단 항목

### BLOCKER C1 — 선수 진단이 단원 핵심 개념을 이미 안다고 가정함

- 위치: `docs/specifications/NEXT_BATCH/M3-06/lesson-spec.json`, `.prerequisiteSkills[0]`
- 현재 문구: “x−a로 나눈 나머지가 P(a)임을 말한다.”
- 근거: M3-06 목표는 나머지정리로부터 인수정리를 설명하고 적용하는 것이다. 해당 정리는 이 단원의 새 학습 내용인데, 진단에서 이미 알고 있어야 한다고 요구한다. 초보 학습자는 선행 개념이 부족하다는 이유로 새 개념 학습을 시작하지 못할 수 있다. 같은 문제가 다른 단원의 진단에도 있는지 확인이 필요하다.
- 수정 요청: 실제 선행 기능(다항식에 수 대입, 부호 있는 정수 계산, 인수의 뜻·일차방정식의 해 등)만 준비도 진단에 두고, 나머지정리/인수정리는 사전 노출 진단이 아니라 학습 전후 확인 문항으로 이동한다. 단원 제안 선수 ID가 변경되는 것은 아니며, 진단 상태는 준비도 안내로만 사용한다.

## 권고 수정 (차단 해제 전 반영 권장)

### R1 — 복소수에서 제곱근 기호의 뜻과 방정식의 두 해 구분

- 위치: `src/data/proposal-lessons/drafts/M3-08.json`, `blocks[concept].sections[1]`; `docs/specifications/NEXT_BATCH/M3-08/lesson-spec.json`, `.objectives[0]`
- 현재 내용은 `√(−a)=√a·i (a>0)`를 바로 사용하고 별도 설명 없이 `√(−25)=5i` 문항을 준다.
- 수학적으로 의도된 주값 표기는 통상 맞지만, 초보 학습자는 이를 `x²=−25`의 해가 하나뿐이라는 주장으로 오해할 수 있다. 실수 제곱근 기호에서 새 수 체계로 넘어가는 구간이므로 표기 범위를 분명히 해야 한다.
- 수정 요청: “기호 `√(−a)`는 이 자료에서 주값 `i√a`를 뜻한다. 방정식 `x²=−a`의 해는 `±i√a` 두 개다”를 설명하고, 문항은 기호값을 묻는지 방정식의 해를 묻는지 명시한다.

### R2 — M3-07 치환 도입 문장의 잘못된 식 예시를 더 명료하게 표시

- 위치: `src/data/proposal-lessons/drafts/M3-07.json`, `blocks[concept].sections[0].body`
- 현재 문장은 `(A−1)(A+1)=(x²−2)(x²)`라는 잘못된 대입을 피하라고 설명한다. 의도는 오답 경고로 읽히지만, 초보자는 등호가 왜 틀렸는지 혹은 올바른 식인지 즉시 알아보기 어렵다.
- 수정 요청: 정답 치환 `A=x²`에서 `(A−1)(A+1)`이 `(x²−1)(x²+1)`로 복원됨을 먼저 쓰고, 잘못된 복원은 오답 예시 상자에 넣어 두 인수를 각각 대입해야 함을 설명한다.

## 검토 중 미결/범위 한계

- 공식 성취기준 매핑은 미검증으로 적절히 보류했다. 조사 보고서는 교육부 발표 페이지를 맥락 자료로 확인했으며, 수학과 교수학습 자료·학생 오개념 관련 외부 자료를 추가 확인하지 않았다. 현재 오개념은 초안 작성자의 가설로 취급해야 한다. 연구 담당자는 다음 반복에서 실제 출처를 추가하거나, 외부 연구 근거가 아닌 설계 가설임을 명시한다.
- 상호작용 ID `factor-theorem`, `polynomial-factorization`, `complex-plane`, `complex-operations`, `quadratic-discriminant`의 계약·renderer 지원은 별도의 개발 확인이 필요하다. 콘텐츠 초안만으로 구현을 확인한 것으로 간주하지 않는다.
- M3-07 문제 M3-07-p01의 답은 실수 계수에서 맞다. 다만 `x²−3`은 실수 범위에서 더 인수분해할 수 있으므로, “인수분해한 것”이 단일 최종형을 뜻하지 않도록 보기와 발문에 “다항식 인수의 곱으로 나타낸 것” 등 범위를 분명히 하는 편이 좋다.

작성자가 C1, R1, R2를 반영했다고 보고해 해당 파일을 다시 확인했다.

- R1: M3-08은 `√(−a)`를 주제곱근 표기로 설명하고, `z²=−9`의 두 해가 `±3i`임을 따로 보여 준다. 기호값과 방정식 해를 구별하도록 문항에도 반영됐는지 각 관련 항목을 확인했으며 혼동을 유발하는 기존 내용은 해소됐다.
- R2: M3-07 치환 도입은 A 정의 후 올바른 두 인수에 각각 역치환하는 과정으로 다시 썼다. 혼동을 주던 잘못된 등식 문장은 제거됐다.
- 조사 상태: `research-report.md` 및 `sources.json`에 교수법·오개념 근거를 독립적으로 확인하지 못했다고 명시하고, 해당 설명은 작성자 가설로 한정했다. 교육부 발표 페이지는 맥락 자료로만 두고 공식 단원 매핑은 여전히 미검증이다. 이를 연구 결과나 공식 정합성으로 과장하지 않는다.
- 게시 경계: 다섯 수업 초안과 30개 문항 초안은 여전히 draft, 사람 검수/승인 0건, 게시 승인 false이며 평가 문항은 없다.
