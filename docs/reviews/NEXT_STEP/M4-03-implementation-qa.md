# M4-03 구현 및 QA 기록

- 단원: 두 직선의 위치 관계
- 구현 상태: 개발 프리뷰 연결, 공통 lesson renderer 사용.
- 실험실: 두 직선의 유한 기울기/절편을 조절해 일치·평행·교차·수직을 구분하고 기울기 곱을 문자로 확인한다. 순수 helper는 수평선/수직선 조합의 예외도 검증한다.
- 문제: 서버 전용 draft 어댑터의 연습 초안 6개/3 원형. 평가 없음.
- 기록 및 공개 게이트: `unitProgress["M4-03"]` 격리, 정답 서버 전용, production preview 차단, 콘텐츠 draft 유지.
- 독립 검토 주의: 기존 worked example은 평행/일치 사례에 한정되어 수직 조건과 수평·수직 예외를 시범하지 않는다. 해당 사례를 포함한 풀이 예제 보강이 필요하다.
- 한계: UI 조절기는 유한 기울기만 다루며 수직선은 수평선과의 직각 관계를 helper 경계 테스트로 검증한다.
- 사람 검수/게시 승인: 미완료.
