# M5-04~M5-08 콘텐츠 독립 재검토 요약

Research의 family/skill 정렬 수정 후 다섯 단원 원본을 다시 읽었다. 총 30개 문항을 답과 풀이로 독립 계산하고 보기 및 정답 키를 대조했다. 현재 데이터에서 수정 요청이 남은 family/skill 불일치는 발견하지 못했다. 정답/키 오류나 선택지 중복도 없다. 모든 문항은 draft로 유지되며 본 검토는 승인·게시 처리가 아니다.

| 단원 | 최신 가족 구성 | 검토 |
|---|---|---|
| M5-04 | 곱·몫 전개 #01/#02; 로그 합·차 결합 #03/#04; 밑 변환 #05/#06 | 분류·skill 정렬 및 계산 확인 |
| M5-05 | 로그 정수부분/구간 #01/#03; 표준형/정규화 #02/#05; 근삿값 계산 #04/#06 | 분류·skill 정렬 및 계산 확인. 이전 #01 선택지 중복 해결 확인 |
| M5-06 | 기본 지수 성질 #01/#04; 단조성 #02/#05; 이동 그래프 #03/#06 | 분류·skill 정렬 및 계산 확인 |
| M5-07 | 기본 로그 성질 #01/#05; 역함수/대응점 #02/#04; 이동 로그 그래프 #03/#06 | 분류·skill 정렬 및 계산 확인 |
| M5-08 | 지수방정식 #01/#04; a>1 부등식 #02/#05; 0<a<1 부등식 #03/#06 | 분류·skill 정렬 및 계산 확인 |

## 공통 검사

- 가족 순 키열: M5-04 `ACBBAC`, M5-05 `BCACAB`, M5-06 `CCBAAB`, M5-07 `ABBCCA`, M5-08 `BBCCAA`. 각 열에서 A/B/C가 각각 2회이고 서로 다르다.
- 30문항 전부 키 ID가 보기와 연결되고, 세 보기가 서로 다르며 정답 값이 rationale과 일치한다.
- runtime lesson 초안은 각 15개 학습 단계와 8개 블록을 포함하며 `publicationApproved:false`다.
- runtime schema를 앱 registry로 파싱하는 검증은 아직 실행하지 못했다. 공식 교육과정 대응 및 출처 확인도 이 검토의 승인 범위 밖이다.

## 다음 인계

기존 family/skill 검토 지적은 현재 파일에서 해소되어 닫는다. 구현 전에는 runtime schema 연동 검증과 별도 콘텐츠/출처 검수 기록이 필요하다. 승인되지 않은 문항은 계속 draft로 둔다.
