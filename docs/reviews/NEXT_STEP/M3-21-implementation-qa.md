# M3-21 구현 및 QA 기록

- 단원: 행렬과 행렬의 연산
- 구현 상태: 개발 프리뷰 연결. 초안 JSON은 수정하지 않았고 공통 lesson renderer와 unitId 기반 전용 실험실을 사용한다.
- 실험실: 2×2 행렬의 합·실수배·곱을 제한된 정수 조절기로 비교하고 행×열 내적 중간식을 텍스트로 표시한다.
- 문제: 서버 전용 draft 어댑터를 통해 연습 초안 6개/3 원형만 연결했다. 평가 없음. 답·풀이가 public DTO에 포함되지 않고 production preview는 차단된다.
- 기록: 시도와 블록 완료는 `unitProgress["M3-21"]`로 격리된다. 기존 루트 진도·평가 점수는 그대로 둔다.
- 독립 검토 주의: 명세 예제는 성분 읽기 두 항목만 시범한다. 연산 크기 조건, 실수배, 행렬 곱을 각각 보이는 풀이 예제 보강이 필요하다. 현재 UI 상호작용은 해당 조작을 제공하지만 이를 worked example 대체로 간주하지 않는다.
- 한계: 2×2 정수 범위에 한정; 일반 크기 행렬 입력/연산 및 공식 성취기준 매핑은 미구현/미확인.
- 사람 검수/게시 승인: 미완료. 콘텐츠 상태는 draft.
- batch verification: `docs/reviews/NEXT_STEP/M3-21-M4-03-batch-qa.md`.
