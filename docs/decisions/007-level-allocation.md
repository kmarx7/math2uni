# ADR-007 · 사용자 목표 수량을 반영한 별도 학습 경로

- 작성 역할: Curriculum Architect
- 상태: **설계 선택 완료 · 제안 경로 구현 기준 · canonical curriculum 등록 아님**
- 결정일: 2026-11-03
- 결정 근거: 사용자의 최신 목표 `12/14/18/22/24/20/22/18/20` 및 기존 단원 식별자 보존 지시
- 관련 문서: [마스터 학습 경로 결정안](../reviews/NEXT_STEP/curriculum-path-proposal.md), `src/data/proposals/learning-path.json`

## 맥락

기존 상세 제안은 LEVEL 0~8에 `12/20/20/22/20/24/24/20/8`개를 둔다. 사용자는 최신 목표 배분을 `12/14/18/22/24/20/22/18/20`으로 지정했다. 총수는 모두 170이지만 LEVEL 1~8별 주제 경계와 단원 ID 접두어가 새 배분과 일치하지 않는다.

공식 170개 단원 원본은 제공되지 않았다. 따라서 기존 단원 의미나 ID를 새 기준에 맞게 덮어쓰거나 재번호화하지 않고, 별도 학습 경로가 기존 ID를 참조하도록 한다. 이 경로는 Math 90 자체 설계 제안이며 국가 교육과정 정본으로 취급하지 않는다.

## 결정

1. 최신 사용자 수량 `12/14/18/22/24/20/22/18/20`을 Math 90 제안 경로의 고정 배분으로 쓴다. 두 과거 대안인 LEVEL 7/8 `20/18`은 채택하지 않는다.
2. 기존 170개 식별자, 단원 제목, 역사적 `Unit.level/order`, 콘텐츠·진도 참조는 보존한다. 새 소속은 별도 `pathLevel/pathOrder`만 사용한다.
3. 경로 LEVEL 1 표시명은 `수·문자와 식·초기 방정식`, LEVEL 2는 `중학 대수·공통수학 대수 진입`으로 넓힌다. 이는 수 기초와 고교 다항식·방정식이 실제 배치에 포함된다는 점을 숨기지 않기 위한 경로 표시명이다. 개별 단원 제목은 바꾸지 않는다.
4. LEVEL 7에는 M7-01~M7-18을 두고, M7-19(모평균 추정)와 M7-20(모비율 추정)은 LEVEL 8의 첫 두 `first-instruction-candidate`로 배치한다. 두 단원은 그곳에서 처음 가르치는 통계 추정 개념이며, 전이/복습 문항으로 잘못 분류하지 않는다. 선수 단원 M7-18, M7-14, M7-16은 LEVEL 7에 남는다. 그 다음에 기존 LEVEL 8 응용·점검·전략 단원을 둔다.
5. 공식 성취기준 코드, 직접 수능 출제 여부, 운영 공개 승인은 이 배분 결정에서 추론하지 않는다. 해당 근거가 확인되기 전까지 제안 상태를 유지한다.

LEVEL 8로의 통계 추정 배치는 사용자 수량을 만족하기 위한 명시적 학습 설계 선택이다. 원문 교육과정과 평가 범위의 직접 대조가 끝나지 않았으므로 추정 단원의 위치 적합성은 공식 범위 검증이 아니다. 사용자 수량은 제안 경로에 적용하지만, 이 교육적 위험을 문서와 데이터에 계속 표시한다.

## ID·순서·선수 검증

경로에는 M0-01~M0-12와 M1~M8 제안 목록의 158개 ID를 각각 한 번 포함한다. 경로 수량은 `[12,14,18,22,24,20,22,18,20]`, 총 170개다. 제안 데이터에 기록된 선수 단원은 경로 순서에서 모두 선수보다 뒤에 오도록 배치했다. M7-19와 M7-20은 각각 M7-18 및 M7-19 뒤에서 처음 소개된다.

기존 제안의 `(unitId, title, level, order)`는 보존하고 새 경로만 다르게 순서화한다. 새로운 ID는 생성하지 않으며 기존 점수나 계정 진도를 이 경로에 자동 이전하지 않는다.

## 영향

- 계획 UI의 LEVEL별 이름·수량과 170개 슬롯 배치는 사용자 목표와 일치해야 한다.
- 경로 데이터 검사는 요청/제안 수량 일치, 170개 ID 완전·유일 포함, 전역 순서, 선수 선행을 계속 검증해야 한다.
- 기존 `first-instruction-candidate` 표시를 LEVEL 8 전체에서 금지하는 검사 규칙은 M7-19/20 예외를 허용하도록 보완해야 한다. 예외를 추가할 때는 이 두 ID에 한정해 의미와 선수 조건을 검증한다. `transfer-candidate`로 낮춰 표시하는 우회는 금지한다.
- 학습 화면, canonical curriculum, assessment/mastery 경계, 사용자 기록은 이번 문서 결정만으로 변경하지 않는다.

## 완료 상태와 남은 외부 검증

Math 90 내부 경로의 수량과 표시명 선택은 최신 사용자 지시에 따라 결정했다. 이전 문서의 “LEVEL 7/8 수량을 사용자가 선택해야 함”, “LEVEL 1/2 제목이 결정되지 않음”은 닫힌 결정으로 간주한다.

다음은 여전히 별도 증거·검수가 필요하다.

- 공식 교육과정 원문과 단원별 성취기준의 직접 대조 및 정확한 코드 확인
- 추정 단원의 LEVEL 8 첫 교수 배치와 전 경로의 교육적 타당성에 대한 전문 사람 검토
- 170개 단원 전체 콘텐츠·문항·저작권/이용권리 사람 검수
- canonical manifest 등록과 운영 공개를 위한 별도 승인

위 항목이 끝나기 전 제안안은 `proposed`로 유지하며, canonical coverage·공식 코드 매핑·게시 승인 상태를 만들지 않는다.
