# ADR-007 · 새 LEVEL 배분과 기존 단원 정체성 보존

- 작성 역할: Curriculum Architect
- 상태: 변경 제안 · 검토 대기
- 근거: 사용자의 멀티 에이전트 마스터 지시(2026-11-01), 기존 `docs/CURRICULUM_PROPOSAL.md` v0.1.0 및 `src/data/curriculum-proposal.ts`
- 범위: 교육과정 구성 충돌을 기록한다. 프로그램 코드·등록 목록·기존 ID를 변경하지 않는다.

## 확인된 차이

| --- | ---: | ---: | ---: | --- |

| 2 | 20 | 18 | -2 | 중학 대수와 함수·도형 경계 재검토 필요 |
| 3 | 22 | 22 | 0 | 기존 공통수학1 기반과 새 중학 함수·기하·확률은 주제가 다름 |
| 4 | 20 | 24 | +4 | 기존 공통수학2 기반만으로 새 고교 공통수학 범위를 대표할 수 없음 |

현재 학습 등록과 실제 기록은 M0-01~M0-12에만 있다. 그러나 제안안의 M1~M8 ID도 문서와 화면에서 이미 참조되므로, 제안 단계라는 이유만으로 같은 ID에 다른 제목·개념을 덮어쓰지 않는다. 기존 제안의 단원 순서도 유지한다.

## 당장 적용하는 결정

1. 새 요청의 LEVEL 수량을 **새 마스터 설계 기준**으로 기록한다.
2. 기존 170개 제안 메타데이터 v0.1.0은 변경 없이 보존한다. 새 기준과 정렬되지 않았다는 상태를 명시한다.
3. M0-01의 공동 설계·검증과 현재 12단원의 앱 기능은 배분 충돌과 독립적으로 진행한다.
4. 새 기준에 맞는 상세 170개 목록을 검증 완료했다고 보고하지 않는다. 현재의 검증 대상은 기존 제안안의 무결성과 새 기준의 합계·충돌 기록이다.
5. 공식 교육과정의 단원별 성취기준을 확인하지 않은 상태에서 새 배분을 공식 목록이나 공식 코드로 정당화하지 않는다.

## 정체성을 보존하는 후속 선택지

### A. 기존 목록은 보존하고, 별도 학습 경로의 소속을 제안한다 (권장)

단원 정체성(`unitId`, 기존 `level`, 기존 `order`)과 새 학습 경로의 위치(`trackId`, `pathLevelId`, `pathOrder`)를 분리한다. 예를 들어 기존의 고교 다항식 단원은 M3 계열 ID를 보존하면서 새 마스터 경로 LEVEL 4의 학습 후보로 배치할 수 있다. 이 경우 ID의 숫자는 역사적 식별자이고 새 경로 소속을 뜻하지 않는다는 계약을 명시해야 한다.

- 장점: 기존 참조·계정 기록·문항·선수 개념을 보존한다. 경로를 바꾸어도 단원 자체를 바꾸지 않는다.
- 제한: 현재 `Unit.id`와 `Unit.level`의 접두어 일치 검사는 유지하고, 별도 경로 검사를 새로 설계해야 한다. 기존 순서와 새 경로 순서를 혼합하지 않는다.
- 필요한 검수: 새 경로 170개 슬롯의 정확한 수량, 각 단원의 주제 적합성, 선수학습의 선행 배치, 통합/분리되는 단원의 동등성, 신규 실전 단원의 별도 목표.
- 아직 하지 않은 일: 170개 슬롯별 단원 배치나 앱 데이터 마이그레이션. 이 문서는 그 배치를 승인하지 않는다.

### B. 새 목록을 별도 버전·별도 정체성으로 설계한다

새 단원을 만들어야 하는 경우 기존 ID를 재사용하지 않고 독립 정체성을 부여한다. 버전별 대응표에는 `unchanged`, `split`, `merge`, `new`, `retired-in-track`를 기록한다. 기존 ID를 삭제하지 않으며 학습 기록의 자동 이관도 하지 않는다.

- 장점: 주제 범위가 실제로 달라진 단원을 같은 ID로 속이지 않는다.
- 제한: 새 식별자 형식과 대응표 계약, 사용자 검토, 버전 전환 UI가 필요하다. 현재 M[0-8]-NN 형식을 무작정 다시 번호 매기는 방식은 허용하지 않는다.

### C. 기존 단원을 즉시 새 LEVEL로 재번호화한다 (채택하지 않음)

기존 문서·문항·경로 참조를 깨뜨리며 동일 ID의 의미가 바뀔 수 있다. 사용자 지시의 ID 안정성과 충돌하므로 시행하지 않는다.

## 다음 교육 검토 작업

- 새 LEVEL 1의 문자·식 14개와 LEVEL 2 중학 대수 18개의 내용 경계를 먼저 정한다.
- 기존 단원의 목표·기술 ID를 기준으로 대응표를 만들고, 숫자 수량을 맞추기 위한 기계적 합치기/쪼개기를 피한다.
- LEVEL 3의 함수·기하·확률, LEVEL 4의 고교 공통수학 선행관계를 교차 검토한다.
- LEVEL 5~7은 공식 과목 범위와 주제를 대조하되 검증되지 않은 성취기준 코드는 비워 둔다.
- LEVEL 8의 20개 실전 단원은 사고 전략·독립 평가·교정과 재평가 목표로 구분한다. 20회분 시험이나 성적 효과를 이미 확보했다고 표현하지 않는다.

## 승인·완료 상태

- 새 배분 총계 170: 사용자 지시에서 확인.
- 기존 ID/순서 보존: 이번 교육 설계 작업에서 유지.
- 새 기준의 상세 170개 메타데이터: 미정렬 · 검토 필요.
- 기존 12단원 외 전체 콘텐츠: 미구현.
- 사람의 교육 검수/콘텐츠 게시 승인: 대기.

이 결정 기록은 충돌을 숨기지 않고 다음 검토의 선택지를 제공한다. 프로그램 변경이나 데이터 이관에 대한 사용자 승인을 대신하지 않는다.
