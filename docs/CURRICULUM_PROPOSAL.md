# 170단원 교육과정 제안안 v0.1.0

2026-11-01 작성. **구성 검토용 제안이며 정본·운영 승인·170개 학습 콘텐츠 완성을 뜻하지 않는다.** 기존 LEVEL 0 12개 ID/제목/순서/개념은 그대로 보존한다. 새로운 M1~M8 ID는 제안 상태이다. 원본 목록이 추후 제공되면 충돌을 검토한 뒤 확정한다.

## 설계 근거와 범위

- [교육부 2028 대입 개편 확정안](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=97551&lev=0): 대수·미적분Ⅰ·확률과 통계를 수능 대비 중심으로 둔다. 미적분Ⅱ·기하의 심화 선택 내용을 목표 범위로 확대하지 않는다. 기초 평면도형·삼각비·좌표기하는 후속 개념의 선수학습으로 구분한다.
- [교육부 2028 수능 예시문항 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=103113&lev=0&m=020402&opType=N&s=moe&statusYN=W): 추후 평가 설계에서 확인할 자료이다. 문항·해설을 복제하거나 독립 평가로 제공한 것은 아니다.
- [한국과학창의재단 고등학교 수학 용어 안내자료 개발, 2025-12](https://cdn.kosac.re.kr/files/cms/attach/202601/4cfcbd23d3b144bb93df4a1b5f15abc5_1769567020530.pdf): 2022 개정 과목 용어를 참고했고 표본비율·모비율 추정을 포함했다. 이 자료가 프로젝트 단원 수·순서·단원별 성취기준 연결을 승인하는 것은 아니다.

위 자료는 과목 범위와 용어의 근거이다. **170개로 나눈 수량·단원명·순서·선수 연결은 Math 90 자체 설계 제안**이다. 공식 성취기준 코드는 검증 전이므로 전부 빈 배열이다. 자세한 과목 내 포함/제외 범위와 성취기준 대응은 교육과정 원문을 기준으로 추가 검수해야 한다. 본 제안은 공식 범위 전체에 대한 대조 검증 완료를 주장하지 않는다.

## 데이터와 검토 화면

- 새 제안 단원 원본: `src/data/proposals/units.json` (명시적 ID, 제목, 두 개념, 선수 단원, 시각화)
- 기존 단원과 합친 제안: `src/data/curriculum-proposal.ts`
- 계약/검사: `src/contracts/curriculum-proposal.ts`, `src/modules/curriculum/proposal.ts`
- 로그인 후 `/curriculum/plan`: 170개 상세 검색·LEVEL 필터·목표/평가 계획·선수 연결·JSON 내려받기

신규 각 단원은 두 개념으로부터 목표·문제 유형의 메타데이터 초안을 구성한다. 목표는 실제 콘텐츠를 작성하면서 평가 가능한 수행 기준으로 구체화한다. 본문·예제·조작·독립 연습·형성평가·해설·문항 수는 아직 구현하지 않았다. 선수 단원은 양쪽 명시 개념 ID로 해석한다. 선행 단원 전체를 숙달해야 한다는 제안이므로 개념 단위 최소 요건은 콘텐츠 검토에서 더 정밀하게 조정한다.

제안 객체는 `status: proposed`, `coverage: partial`, 빈 canonicalManifest를 강제한다. 실서비스 `curriculum.ts`와 학습·채점·진도·인증 경계는 제안 데이터를 가져오지 않는다. 계획 화면의 상세 열기·검색·내려받기는 읽기 작업이며 승인이나 등록 작업이 아니다.

## 다음 구현 묶음

구성 확인 후 M1-01~M1-05를 먼저 구현한다. 정수의 부호·유리수·기초 지수법칙·문자 대입을 학습하고 기존 부호·분수 조작을 확장한다. 각 단원에서 블록·기본/변형/응용·분리 평가·오답·지연 복습·계정 저장·모바일 검사를 완료한다. 문항은 사람 승인 전 개발 검토용으로만 제공한다.

정본 확정은 제목만 승인하는 작업이 아니다. 단원 수/순서/개념 ID·선수 그래프·공식 범위 검토를 함께 확인하고 변경 기록을 남겨야 한다. 확정 시에는 검토된 ID/순서 manifest와 버전을 별도 기록한다. 구성 확인과 AI 문항 게시 승인은 서로 다른 절차이다. 현재 전체 canonical 게이트는 계속 실패한다.
