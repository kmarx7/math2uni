## 이번 MVP
대시보드, LEVEL별 준비 상태와 LEVEL 0 메타데이터, M0-01 8종 블록, 자리값 실험, 원형별 연습, 서버 채점, 제출 후 해설, 전체 제출 형성평가, 개념 숙달, 오답노트, 복습, 브라우저별 로컬 프로필. 숙달은 최초 독립 정답만 가산하고 힌트/재시도 정답은 가중치를 낮춘다. 같은 문항·같은 버전 반복은 마지막 증거 하나만 반영한다. 복습 간격은 1/3/7일, 오답 시 다음 날로 재설정한다.

## 제공 자료에 따른 제한
170개 정본 목록 미제공: LEVEL 0는 편집 초안 12개, M0-01만 published. 전체 정본 완전성 검사는 실패 상태를 유지하며 공식 교육과정 매핑은 비어 있다. 로컬 기록은 인증 없는 학습 보조 지표이며 실제 평가 근거로 확정할 수 없다.
