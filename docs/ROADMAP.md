# 구현 계획과 완료 기준

현재는 170단원 단계별 확장의 경로 설계 검토 단계이다. 별도 `learningPath` 제안과 검증된 읽기 전용 검토 화면이 있으며, 정본·운영 경로는 아직 확정되지 않았다. 상세 묶음과 종료 조건은 [DELIVERY_PLAN.md](DELIVERY_PLAN.md)를 따른다.

## 완료한 기능

- 7개 엔진·Zod 계약·공통 블록 학습 화면·서버 채점·오답·숙달·지연 복습
- Supabase 이메일/비밀번호 인증, 계정별 PostgreSQL CAS 저장, 실제 RLS 검사. 사용자가 로그인 성공 확인
- LEVEL 0 기존 12개 ID의 목표·설명·예제·조작·연습·평가 콘텐츠 초안
- 고정 72문항(연습/평가 각 36), 33개 풀이 원형, 자리값 생성 샘플 2개
- 단원별 블록/평가/시도 기록, 기존 M0-01 기록 호환, 선수 개념 복습 링크와 다음 단원 이동

- 170단원 전체 구성 제안, 누락/중복/선수 검사, 읽기 전용 계획 화면·검색·JSON 내려받기. 정본 등록은 미완료

숙달은 독립 정답을 가산하고 힌트/재시도 정답은 가중치를 낮춘다. 같은 문항·버전은 마지막 증거만 반영한다. 24시간 이내 재응시는 재시도이며 이후 도움 없는 지연 복습은 독립 증거로 회복할 수 있다. 복습 간격은 1/3/7일, 오답 시 다음 날로 재설정한다.

## 미완료 범위와 다음 단계

- 원본 170단원 정본 확보 또는 사용자 검토를 거친 교육과정안 확정, ID/순서/선수 그래프 동결
- 승인된 순서로 다음 LEVEL을 5~10개 단원씩 구현·검증하며 누적 170단원까지 확장
- 사람의 수학교육 검수와 문항 게시 승인. 현재 전부 자동 검사 상태이며 개발 검토 모드에서만 문제 제공
- 검증된 공식 성취기준 매핑, D4~D5 문항, 독립 모의평가와 학습 효과 검증
- 관리자 검수 UI, 정답률 기반 선수 진단, 접근성 사용자 평가
- Python/SymPy 검증 및 AI 튜터·대량 생성은 승인·격리 설계 이후

정본 canonical 게이트는 현재 실패한다. 일반 테스트 통과를 170단원 완료나 콘텐츠 운영 승인으로 보고하지 않는다. 실제 실행 결과는 [VERIFICATION.md](VERIFICATION.md)를 참조한다.

## 멀티 에이전트 공동 개발 단계

세 역할의 병렬 조사·설계·독립 수학 검사·개발 인계를 실제 수행했다. M0-01은 6소단원·15교수단계(심화1단계예정), 신규 30초안/10원형 확장 묶음과 3개 조작 활동을 추가했다. 기존 완료를 보존하도록 core/extended 점수·숙달 증거를 분리했다. 단계별 산출물·템플릿 설치 제한은 [MULTI_AGENT.md](MULTI_AGENT.md)를 따른다.

최신 LEVEL 배분 12/14/18/22/24/20/22/18/20은 요청 기준으로 보존한다. 기존 ID를 유지하는 별도 학습 경로 제안은 `learningPath`에 추가했지만, 교육 검토안의 LEVEL 7/8 수량 조정(20/18)과 LEVEL 1/2 명칭 변경은 사용자 검토 대기다. 새 기준에 맞춘 승인된 상세 170 메타데이터, D4/D5·조건카드조작, 사람 검수·운영 게시, 콘텐츠 구현은 미완료이다. 다음은 경로 제목/수량 검토를 마친 뒤 M1-01~M1-05의 교육 명세와 콘텐츠를 단계별로 구현하는 것이다.
